19 modular infrastructure packages for Go backends built on Gin and Uber Fx — logging, database, cache, responses, validation, security, middleware and more. Jungo is built on them, but each package works completely standalone.

19 package hạ tầng độc lập cho Go backend xây dựng trên Gin và Uber Fx — logging, database, cache, response chuẩn, validation, bảo mật, middleware và hơn thế nữa. Jungo sử dụng bộ kit này làm nền tảng, nhưng từng package đều có thể tách rời và tích hợp vào bất kỳ dự án Go nào.

Four rules that make every package predictableBốn nguyên tắc thiết kế nhất quán cho mọi package

Learn these once, then every package in Junkit follows the exact same pattern.

Chỉ cần nắm 4 nguyên tắc này, bạn sẽ dễ dàng sử dụng và tích hợp bất kỳ package nào trong Junkit.

1

Configured by a plain Options structCấu hình tường minh qua struct Options độc lập

No package reads env vars or config files directly (one exception: validation reads, and creates if missing, storage/bootstrap/email_blocklist.conf). Your application builds each Options (Jungo builds them from .env in internal/app/fx.go).

Không package nào tự tiện đọc biến môi trường (.env) hay file cấu hình (ngoại lệ duy nhất: validation đọc, và tạo nếu chưa có, storage/bootstrap/email_blocklist.conf). Ứng dụng của bạn tự khởi tạo Options (trong Jungo, các Options được map từ .env tại internal/app/fx.go).

2

One line to register: ModuleĐăng ký một dòng duy nhất: Module

Supply the Options, then add pkg.Module. Every constructor is also exported, so Fx is never mandatory.

Chỉ cần cung cấp Options, sau đó nạp pkg.Module vào Fx. Tất cả constructor đều được export nên bạn hoàn toàn có thể dùng thủ công mà không phụ thuộc vào Fx.

3

Depend on interfacesLập trình hướng Interface

Responder, Cache[T], storage.Service, Notifier, Verifier, TokenSealer… Swap Redis ↔ memory or real ↔ mock via config; easy to inject fakes in tests.

Responder, Cache[T], storage.Service, Notifier, Verifier, TokenSealer… Dễ dàng chuyển đổi Redis ↔ Memory hoặc Driver thật ↔ Mock qua cấu hình; thuận tiện truyền Fake/Mock khi viết Unit Test.

4

Core never imports optionalPackage lõi không import phụ thuộc tùy chọn

Extension points connect them instead — e.g. postgres.Options.Decorate lets tracer monitor every query without database/postgres ever importing it.

Mở rộng chức năng qua Extension Points — ví dụ postgres.Options.Decorate cho phép tracer ghi nhận mọi câu query mà không bắt database/postgres phải import tracer.

Standard integration flow for any package with a ModuleLuồng tích hợp chuẩn cho package có Module

1 · your configfx.Provide(provideXOptions)
or fx.Supply(x.Options{…})
hoặc fx.Supply(x.Options{…})
2 · Junkitx.Module

3 · your codefunc NewThing(db *postgres.DB…)
Request the component as a constructor parameter (see Uber Fx).
Yêu cầu inject đối tượng qua tham số của constructor (xem Uber Fx).
