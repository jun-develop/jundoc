Junkit · stringx

stringx

String helpers the standard strings package lacks: convert identifiers between snake_case, PascalCase and camelCase, and change the case of the first letter only. The first-letter helpers work on runes, so Vietnamese text is safe.

Các hàm cho chuỗi mà package chuẩn strings chưa có: chuyển tên định danh giữa snake_case, PascalCase và camelCase, và chỉ đổi hoa/thường chữ cái đầu. Các hàm chữ cái đầu làm việc theo rune, nên an toàn với tiếng Việt.

Quick startDùng nhanh

Turn Go field names into JSON keys, feature names into Go identifiers, and fix the first letter of a message.

Biến tên field Go thành key JSON, tên feature thành định danh Go, và sửa chữ cái đầu của một thông báo.

main.go
stringx.ToSnake("AvatarURL")  // "avatar_url"
stringx.ToSnake("APIKey")     // "api_key"
stringx.ToSnake("UserID")     // "user_id"

stringx.ToPascal("order_item") // "OrderItem"
stringx.ToCamel("order_item")  // "orderItem"

stringx.UpperFirst("đẹp trai") // "Đẹp trai"
stringx.LowerFirst("Hello")    // "hello"

API referenceTham chiếu API

Everything the package exports — signatures copied from junkit/stringx.

Mọi thứ package export — chữ ký chép từ junkit/stringx.

funcToSnake
func ToSnake(s string) string
  • Converts a PascalCase or camelCase identifier to snake_case; every letter is lower-cased.
  • Chuyển định danh PascalCase hoặc camelCase sang snake_case; mọi chữ cái đều viết thường.
  • Inserts _ before a capital that follows a lower-case letter or a digit (Item2Name → item2_name), and before the last capital of an acronym that starts a new word (HTTPServer → http_server).
  • Chèn _ trước chữ hoa đứng sau chữ thường hoặc chữ số (Item2Name → item2_name), và trước chữ hoa cuối của một từ viết tắt khi nó mở đầu từ mới (HTTPServer → http_server).
  • Works on Unicode capitals too, not only ASCII: ĐơnHàng → đơn_hàng.
  • Áp dụng cho cả chữ hoa Unicode, không chỉ ASCII: ĐơnHàng → đơn_hàng.
funcToPascal
func ToPascal(s string) string
  • Splits s on _ and joins the parts with each part's first letter upper-cased (UpperFirst).
  • Tách s theo _ rồi nối các phần, mỗi phần viết hoa chữ cái đầu (UpperFirst).
  • Empty parts from __ or a leading/trailing _ disappear: __a__b → AB.
  • Phần rỗng do __ hoặc _ ở đầu/cuối biến mất: __a__b → AB.
funcToCamel
func ToCamel(s string) string
  • ToPascal(s) with the first letter lower-cased: order_item → orderItem.
  • ToPascal(s) với chữ cái đầu viết thường: order_item → orderItem.
funcUpperFirst
func UpperFirst(s string) string
  • Returns s with its first rune upper-cased; the rest is unchanged.
  • Trả về s với rune đầu tiên viết hoa; phần còn lại giữ nguyên.
  • An empty string, or one whose first rune is already upper-case, is returned as is.
  • Chuỗi rỗng, hoặc chuỗi có rune đầu đã viết hoa, được trả về nguyên vẹn.
funcLowerFirst
func LowerFirst(s string) string
  • Returns s with its first rune lower-cased; the rest is unchanged (URL → uRL).
  • Trả về s với rune đầu tiên viết thường; phần còn lại giữ nguyên (URL → uRL).
  • An empty string, or one whose first rune is already lower-case, is returned as is.
  • Chuỗi rỗng, hoặc chuỗi có rune đầu đã viết thường, được trả về nguyên vẹn.

Good to knowCần lưu ý

1Plural acronyms splitTừ viết tắt số nhiều bị táchA lower-case letter right after an acronym starts a new word, so UserIDs → user_i_ds. Name the field UserIds or set the key yourself.Chữ thường ngay sau từ viết tắt mở đầu từ mới, nên UserIDs → user_i_ds. Hãy đặt tên field là UserIds hoặc tự đặt key.
2Not a round tripKhông chuyển ngược lại đượcToPascal does not know acronyms: ToPascal(ToSnake("UserID")) is UserId, not UserID.ToPascal không biết từ viết tắt: ToPascal(ToSnake("UserID")) là UserId, không phải UserID.
3Only _ separatesChỉ _ là dấu táchToPascal and ToCamel split on _ only; spaces and - stay (ToPascal("order item") → Order item). ToSnake adds _ only before capitals and leaves other characters as they are.ToPascal và ToCamel chỉ tách theo _; khoảng trắng và - giữ nguyên (ToPascal("order item") → Order item). ToSnake chỉ thêm _ trước chữ hoa và để nguyên các ký tự khác.
