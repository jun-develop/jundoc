slicex

Slice helpers the standard slices package lacks. Today that is one function: Map, which turns rows into responses and never returns nil, so an empty JSON list is [], not null.

Các hàm cho slice mà package chuẩn slices chưa có. Hiện có một hàm: Map, biến các row thành response và không bao giờ trả nil, nên danh sách JSON rỗng là [] chứ không phải null.

Quick startDùng nhanh

Map database rows to domain values, and domain values to responses.

Ánh xạ row database sang giá trị domain, và giá trị domain sang response.

user_dto.go
type UserResponse struct {
    Name string `json:"name"`
}

func NewUserResponse(u *User) UserResponse {
    return UserResponse{Name: u.Name}
}

func NewUserListResponse(users []*User) []UserResponse {
    return slicex.Map(users, NewUserResponse)
}

ids := slicex.Map(users, func(u *User) int64 { return u.ID })

API referenceTham chiếu API

Everything the package exports — signatures copied from junkit/slicex.

Mọi thứ package export — chữ ký chép từ junkit/slicex.

funcMap
func Map[S ~[]E, E, R any](s S, fn func(E) R) []R
  • Returns fn applied to each element, in order.
  • Trả về kết quả của fn trên từng phần tử, giữ nguyên thứ tự.
  • A nil or empty input gives an empty, non-nil slice: json.Marshal writes [].
  • Đầu vào nil hoặc rỗng cho slice rỗng khác nil: json.Marshal ghi ra [].
  • S ~[]E accepts named slice types too (e.g. type Users []*User).
  • S ~[]E nhận cả kiểu slice có tên (vd. type Users []*User).
