What it doesNó làm gì

The browser gets a token from Google, sends it with the form, your server asks Google's siteverify what it thinks. With Mock the last two steps are skipped and every token passes.

Trình duyệt lấy token từ Google, gửi kèm form, server của bạn hỏi siteverify của Google đánh giá thế nào. Với Mock, hai bước cuối bị bỏ qua và mọi token đều qua.

recaptcha.Module picks the implementation: Options.Mock → *MockVerifier, otherwise *Client. Either way it is provided as recaptcha.Verifier.

recaptcha.Module tự chọn bản cài đặt: Options.Mock → *MockVerifier, ngược lại *Client. Dù thế nào nó cũng được cung cấp dưới dạng recaptcha.Verifier.

// provideRecaptchaOptions builds recaptcha.Options from cfg.Recaptcha.
func provideRecaptchaOptions(cfg *config.Config) recaptcha.Options {
	return recaptcha.Options{
		SecretKey: cfg.Recaptcha.SecretKey,
		MinScore:  cfg.Recaptcha.MinScore,
		Mock:      cfg.Recaptcha.Mock,
	}
}

From config.RecaptchaConfig: RECAPTCHA_SECRET_KEY, RECAPTCHA_MIN_SCORE (default 0.5), RECAPTCHA_MOCK (default true — in every environment, see gotchas).

Từ config.RecaptchaConfig: RECAPTCHA_SECRET_KEY, RECAPTCHA_MIN_SCORE (mặc định 0.5), RECAPTCHA_MOCK (mặc định true — ở mọi môi trường, xem phần lưu ý).

main.go
var verifier recaptcha.Verifier
if os.Getenv("APP_ENV") == "production" {
	// func NewClient(opts Options, httpClient *http.Client) *Client
	verifier = recaptcha.NewClient(recaptcha.Options{
		SecretKey: os.Getenv("RECAPTCHA_SECRET_KEY"),
		MinScore:  0.7,
	}, nil) // nil → http.DefaultClient (no timeout!)
} else {
	verifier = recaptcha.NewMockVerifier()
}

Without Fx, Options.Mock does nothing — NewClient ignores it. Choose the implementation yourself, as above.

Không dùng Fx thì Options.Mock không có tác dụng — NewClient bỏ qua nó. Tự chọn bản cài đặt như trên.

Use it in 30 secondsDùng ngay trong 30 giây

Protect a sign-up form. Hover an explanation to light up its lines.

Bảo vệ một form đăng ký. Rê chuột vào giải thích để làm sáng các dòng tương ứng.

signup_handler.go
var ErrBot = response.New(response.Forbidden,
    "recaptcha_verification_failed")

type SignupRequest struct {
    Email          string `json:"email" binding:"required"`
    RecaptchaToken string `json:"recaptcha_token" binding:"required,max=4096"`
}

func (h *SignupHandler) Signup(c *gin.Context) {
    var req SignupRequest
    if err := c.ShouldBindJSON(&req); err != nil {
        h.responder.SendWithData(c, 422, "validation_error",
            h.validator.GetValidationErrors(c, err))
        return
    }

    err := h.verifier.Verify(c.Request.Context(), req.RecaptchaToken, c.ClientIP())
    if err != nil {
        h.logger.Info("recaptcha rejected", zap.Error(err))
        h.responder.Error(c, ErrBot)
        return
    }
    // … create the account
}

2token fieldv3 tokens are long; Jungo caps the field at 4096. Use required if the form must carry one.Token v3 khá dài; Jungo giới hạn field ở 4096. Dùng required nếu form bắt buộc phải có.
3VerifyThe request context cancels the Google call if the client goes away. remoteIP is optional — "" leaves it out.Truyền c.Request.Context() để tự động hủy request tới Google nếu client đóng kết nối sớm. Tham số remoteIP là tùy chọn (truyền "" nếu không cần).
4log, don't leakThe error says why (score, Google error codes) — useful in logs, not for the client. Every error means "reject".Error cho biết lý do (điểm, mã lỗi của Google) — hữu ích trong log, không nên trả cho client. Mọi error đều nghĩa là "từ chối".

              secret, response (= token) and, if non-empty, remoteip as URL
                query parameters (empty body). Errors, in the order they are checked:

            
Gửi POST https://www.google.com/recaptcha/api/siteverify với secret,
              response (= token) và, nếu khác rỗng, remoteip dưới dạng query parameter trên
                URL (body rỗng). Các lỗi, theo thứ tự kiểm tra:
