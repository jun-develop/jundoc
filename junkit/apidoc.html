Junkit · apidoc

apidoc

API docs that cannot drift from the code: the OpenAPI 3 document is built from the request and response structs you already have, and served as an interactive page with Scalar.

Tài liệu API không thể lệch khỏi code: tài liệu OpenAPI 3 được sinh từ chính các struct request và response bạn đã có, rồi hiển thị thành trang tương tác bằng Scalar.

1

What it doesNó làm gì

You describe each route in one line. Everything else is read from code that already exists.

Bạn mô tả mỗi route bằng một dòng. Mọi thứ còn lại được đọc từ code đã có sẵn.

1 · describeapidoc.Route{…}
Method, path, summary, and which struct is the body, query and response.
Method, path, tóm tắt, và struct nào là body, query, response.
2 · read structsjson · form · binding · example
Field names, types, required, min/max, enums, formats and samples come from the tags.
Tên field, kiểu, bắt buộc, min/max, enum, định dạng và giá trị mẫu lấy từ tag.
3 · buildapidoc.Spec(info, ops)
OpenAPI 3 JSON, with your response envelope and error responses.
JSON OpenAPI 3, kèm khung response và các response lỗi của app.
4 · serveapidoc.Register(r, "/docs", …)
Scalar page at /docs, raw document at /docs/openapi.json.
Trang Scalar ở /docs, tài liệu thô ở /docs/openapi.json.

Use it in 30 secondsDùng ngay trong 30 giây

A DTO you already have, one Route per endpoint, then build and serve. Hover an explanation to light up its lines.

Một DTO bạn đã có, mỗi endpoint một Route, rồi build và phục vụ. Rê chuột vào giải thích để làm sáng các dòng tương ứng.

product_dto.go
type CreateProductRequest struct {
    Name  string `json:"name" binding:"required,min=2,max=100" example:"Coffee"`
    Price int64  `json:"price" binding:"required,min=0"`
    Kind  string `json:"kind" binding:"omitempty,oneof=food drink"`
}
main.go
ops := []apidoc.Operation{{
    Route: apidoc.Route{
        Method: http.MethodPost, Path: "/api/v1/products",
        Summary:  "Create a product",
        Body:     CreateProductRequest{},
        Status:   http.StatusCreated,
        Response: ProductResponse{},
    },
    Tag:      "products",
    Security: apidoc.Security{Bearer: true, Permissions: []string{"products:create"}},
}}

spec, err := apidoc.Spec(apidoc.Info{Title: "API", Version: "v1"}, ops)
if err != nil {
    return err
}
apidoc.Register(router, "/docs", "API docs", spec)

typeSecurity · Operation · Info
type Security struct {
    Bearer       bool     // needs "Authorization: Bearer <token>"
    APIKeyHeader string   // needs this header holding a shared secret
    Permissions  []string // permission codes the caller must hold
}

type Operation struct {
    Route           // Path here is the full path
    Tag      string // the group the route is listed under
    Security Security
}

type Info struct {
    Title   string
    Version string
}

Bearer adds 401 and 403 responses; permissions are listed at the top of the route's description.

Bearer thêm response 401 và 403; các permission được liệt kê ở đầu phần mô tả của route.

funcSpec
func Spec(info Info, ops []Operation) ([]byte, error)
  • Paths use Gin's syntax (/users/:uuid) and come out as /users/{uuid}.
  • Path dùng cú pháp Gin (/users/:uuid) và được đổi thành /users/{uuid}.
  • Every success response uses junkit's envelope: status, message, data, api_info.
  • Mọi response thành công dùng khung của junkit: status, message, data, api_info.
  • Errors the route can answer are added: 400 (bad body or path), 401/403 (protected), 422 (validation, with error = field → message).
  • Các lỗi route có thể trả được thêm vào: 400 (body hoặc path sai), 401/403 (route được bảo vệ), 422 (validation, với error = field → message).
funcRegister
func Register(r gin.IRoutes, path, title string, spec []byte)

Serves the Scalar page at path and the document at path + "/openapi.json". Import the JSON into Postman or Insomnia, or generate a frontend client from it.

Phục vụ trang Scalar ở path và tài liệu ở path + "/openapi.json". Có thể import file JSON vào Postman, Insomnia, hoặc dùng để sinh client cho frontend.

Feature chỉ cần viết Docs(); router lo phần còn lại và không cho app khởi động khi thiếu docs.

Good to knowCần lưu ý

1Development only in JungoJungo chỉ bật ở developmentThe docs list every route, internal ones included. Production answers /docs with 404.Docs liệt kê mọi route, kể cả route internal. Ở production, /docs trả 404.
2The page needs the internetTrang cần có internetScalar is loaded from the jsDelivr CDN; /docs/openapi.json works offline.Scalar được tải từ CDN jsDelivr; /docs/openapi.json vẫn dùng được khi offline.
3Headers are free textHeader chỉ là mô tảA header such as X-Device-ID is mentioned in Description; there is no field for it.Header như X-Device-ID được ghi trong Description; chưa có field riêng cho nó.
