func provideMailerOptions(cfg *config.Config, log *zap.Logger) mailer.Options {
	m := cfg.Mail
	if !cfg.IsDevelopment() && (m.Driver == "" || m.Driver == string(mailer.DriverLog)) {
		log.Warn("mailer: MAIL_DRIVER=log outside development; emails are logged, not sent")
	}

	return mailer.Options{
		Driver: mailer.Driver(m.Driver),
		From:   m.From,
		SMTP: mailer.SMTPOptions{
			Host: m.SMTPHost, Port: m.SMTPPort,
			Username: m.SMTPUsername, Password: m.SMTPPassword,
		},
		Brevo: mailer.BrevoOptions{APIKey: m.BrevoAPIKey},
	}
}

Use it in 30 secondsDùng ngay trong 30 giây

Send a welcome email with an HTML and a plain-text version. Hover an explanation to light up its lines.

Gửi mail chào mừng có bản HTML và bản text thường. Rê chuột vào giải thích để làm sáng các dòng tương ứng.

welcome.go
type Welcomer struct {
    mail mailer.Sender // from mailer.Module
}

func (w *Welcomer) Send(ctx context.Context, email, name string) error {
    ctx, cancel := context.WithTimeout(ctx, 30*time.Second)
    defer cancel()

    return w.mail.Send(ctx, mailer.Message{
        To:      []string{email},
        Subject: "Welcome to Jungo",
        HTML:    "<p>Hi " + html.EscapeString(name) + "!</p>",
        Text:    "Hi " + name + "!",
    })
}

API referenceTham chiếu API

Everything the package exports — from junkit/mailer/mailer.go and module.go.

Mọi thứ package export — từ junkit/mailer/mailer.go và module.go.

interfaceSender
type Sender interface {
	Send(ctx context.Context, msg Message) error
}

The only thing you depend on. Every driver opens what it needs per call, so it is safe for concurrent use.

Thứ duy nhất bạn phụ thuộc vào. Mỗi driver mở kết nối cần thiết cho từng lần gọi, nên an toàn khi dùng đồng thời.

  • Needs at least one of To / Cc / Bcc and one of HTML / Text.
  • Cần ít nhất một trong To / Cc / Bcc và một trong HTML / Text.
  • Bcc recipients get the mail but never appear in its headers.
  • Người nhận Bcc nhận được mail nhưng không bao giờ xuất hiện trong header.

Checks the config without contacting the provider: unknown driver, invalid From, missing SMTP host or Brevo key → error. A wrong password or key shows up on the first Send. A nil httpClient gets a 30s timeout; a nil logger is fine.

Good to knowCần lưu ý

1"accepted" is not "delivered""đã nhận" chưa phải "đã tới"Send returns nil once the provider accepts the mail. The provider may still drop it later (unverified sender, blocked recipient) — check its logs (Brevo: Transactional → Logs).Send trả nil khi nhà cung cấp đã nhận mail. Nhà cung cấp vẫn có thể bỏ mail sau đó (sender chưa xác minh, người nhận bị chặn) — xem log của họ (Brevo: Transactional → Logs).
2the log driver logs bodiesdriver log ghi cả bodyOTPs and reset links end up in the log on purpose, for local testing. Never run production on log; Jungo warns at startup if you do.OTP và link reset được ghi ra log có chủ đích, để test local. Đừng bao giờ chạy production với log; Jungo cảnh báo lúc khởi động nếu bạn làm vậy.
3one connection per mail, no retrymỗi mail một kết nối, không retryFine for transactional volume. Retry only belongs in your code if sending twice is acceptable; the brevo driver retries only if the injected *http.Client does (Jungo's does not).Ổn với lượng mail giao dịch. Chỉ nên retry trong code của bạn nếu gửi trùng là chấp nhận được; driver brevo chỉ retry nếu *http.Client được inject có retry (của Jungo thì không).
4a new providernhà cung cấp mớiAnything with SMTP needs only new MAIL_* values. A provider with an HTTP API only gets a new driver file in junkit; apps keep calling Sender unchanged.Nhà cung cấp nào có SMTP thì chỉ cần đổi giá trị MAIL_*. Nhà cung cấp chỉ có HTTP API thì thêm một file driver trong junkit; app vẫn gọi Sender như cũ.
