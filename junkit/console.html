What it doesNó làm gì

Every printing function does the same four things to your format string. The casing step touches only the first character of the format, never the arguments.

Mọi hàm in đều làm cùng bốn việc với chuỗi format của bạn. Bước đổi hoa/thường chỉ chạm vào ký tự đầu tiên của format, không bao giờ chạm vào các tham số.

1 · callSuccessf("done %d", n)
A fmt format string plus arguments.
Một chuỗi format kiểu fmt cùng các tham số.
2 · caseupper / lower
Info, Success, Step → first rune upper-cased. Warn, Fatal → lower-cased (it follows a prefix).
Info, Success, Step → rune đầu viết hoa. Warn, Fatal → viết thường (vì đứng sau tiền tố).
3 · stylecolour + icon
ANSI colour code, an emoji / prefix, the reset code and "\n".
Mã màu ANSI, emoji / tiền tố, mã reset và "\n".
4 · printfmt.Printf → stdout
Always stdout. Fatalf then calls os.Exit(1).
Luôn là stdout. Fatalf sau đó gọi os.Exit(1).

Use it in 30 secondsDùng ngay trong 30 giây

A tiny generator. Hover an explanation to light up its lines.

Một trình sinh code nhỏ. Rê chuột vào giải thích để làm sáng các dòng tương ứng.

main.go
func main() {
    name := os.Args[1]
    console.Stepf("🏗️", "generating feature %s", name)

    if _, err := os.Stat(".env"); err != nil {
        console.Warnf("No .env file, using defaults")
    }

    if err := generate(name); err != nil {
        console.Fatalf("Generate %q: %v", name, err)
    }

    console.Successf("feature %q generated", name)
    console.Infof("next: make migrate-up")
}

func generate(name string) error {
    tmpl, err := os.ReadFile("templates/feature.tmpl")
    if err != nil {
        return console.NewError("template %q: %w", name, err)
    }
    return os.WriteFile(name+".go", tmpl, 0o644)
}
