Junkit · console

console

Colored, one-line status messages on stdout for CLI tools, code generators and main bootstrap — not for request-time logging (use logger for that).

In các dòng trạng thái có màu ra stdout cho công cụ CLI, trình sinh code và phần khởi động trong main — không dùng để log khi xử lý request (hãy dùng logger).

What it doesNó làm gì

Five functions, each printing one colored line to stdout. Each one changes only the first character of the format (never the arguments); Fatalf then exits. The table in Setup lists every prefix and color.

Năm hàm, mỗi hàm in một dòng có màu ra stdout. Mỗi hàm chỉ đổi ký tự đầu tiên của format (không bao giờ đổi tham số); Fatalf sau đó thoát. Bảng ở Cài đặt liệt kê mọi tiền tố và màu.

2

SetupCài đặt

Nothing to wire: no Fx Module, no constructor, no Options. Import it and call the functions.

Không có gì để kết nối: không Fx Module, không constructor, không Options. Import rồi gọi hàm là xong.

import "github.com/jun-develop/junkit/console"

    console.Infof("starting migration for %s", "users")
}

Quick startDùng nhanh

A tiny generator. Hover an explanation to light up its lines.

Một trình sinh code nhỏ. Rê chuột vào giải thích để làm sáng các dòng tương ứng.

main.go
func main() {
    name := os.Args[1]
    console.Stepf("🏗️", "generating feature %s", name)

    if _, err := os.Stat(".env"); err != nil {
        console.Warnf("No .env file, using defaults")
    }

    if err := generate(name); err != nil {
        console.Fatalf("Generate %q: %v", name, err)
    }

    console.Successf("feature %q generated", name)
    console.Infof("next: make migrate-up")
}

func generate(name string) error {
    tmpl, err := os.ReadFile("templates/feature.tmpl")
    if err != nil {
        return fmt.Errorf("template %q: %w", name, err)
    }
    return os.WriteFile(name+".go", tmpl, 0o644)
}

Try itThử ngay

Same casing and prefix logic as the Go code. Formatting is simplified: only %s, %v, %d, %q and %%, all filled with the one argument.

Cùng logic đổi hoa/thường và tiền tố như code Go. Phần format được đơn giản hoá: chỉ %s, %v, %d, %q và %%, tất cả lấy từ một tham số duy nhất.
