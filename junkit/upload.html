upload

Checks an uploaded file — size, extension and the content type sniffed from its first bytes — before you hand it to storage. A .png that is really an HTML page is refused.

Kiểm tra file upload — kích thước, phần mở rộng và content type đoán từ các byte đầu — trước khi đưa cho storage. Một file .png mà thực chất là trang HTML sẽ bị từ chối.

Use it in 30 secondsDùng ngay trong 30 giây

An avatar upload handler. Hover an explanation to light up its lines.

Một handler upload avatar. Rê chuột vào giải thích để làm sáng các dòng tương ứng.

avatar_handler.go
var avatarRule = upload.Image(5 << 20) // JPEG, PNG, WebP up to 5 MB

func (h *Handler) UploadAvatar(c *gin.Context) {
    fh, err := c.FormFile("avatar")
    if err != nil {
        h.responder.Send(c, http.StatusBadRequest, "invalid_avatar_file")
        return
    }

    file, err := upload.Open(fh, avatarRule)
    if errors.Is(err, upload.ErrInvalidFile) {
        h.responder.Send(c, http.StatusBadRequest, "invalid_avatar_file")
        return
    }
    if err != nil {
        h.responder.Error(c, err) // I/O failure, not the client's fault
        return
    }
    defer file.Close()

    url, err := h.storage.UploadFile(c.Request.Context(), file, fh.Filename)
    if err != nil {
        h.responder.Error(c, err)
        return
    }

    h.responder.SendWithData(c, http.StatusOK, "avatar_uploaded", gin.H{"url": url})
}

2ErrInvalidFile → 400Too big, wrong extension, or bytes that are not one of Types. Always the same sentinel, so the client learns nothing about which check failed.Quá lớn, sai phần mở rộng, hoặc nội dung không thuộc Types. Luôn cùng một lỗi sentinel, nên client không biết bước nào thất bại.
3other errors → 500Failing to open the upload's temp file is a wrapped I/O error (upload: open: …), not ErrInvalidFile.Lỗi mở file tạm của upload là lỗi I/O được bọc (upload: open: …), không phải ErrInvalidFile.

funcOpen
func Open(fh *multipart.FileHeader, rule Rule) (multipart.File, error)
  • Rule violation → ErrInvalidFile (the file is closed for you).
  • Vi phạm Rule → ErrInvalidFile (file được đóng giúp bạn).
  • fh.Open failure → wrapped I/O error.
  • fh.Open lỗi → lỗi I/O được bọc.
  • Success → an open file rewound to the start; the caller closes it.
  • Thành công → file đang mở, đã tua về đầu; người gọi tự đóng.

HasType sniffs up to 512 bytes, rewinds, and reports whether the type is one of types (a read or seek error → false). Extension is the lowercased filepath.Ext, dot included ("A.PNG" → ".png").

Good to knowCần lưu ý

1Size is the header's claimfh.Size comes from the parsed multipart form; the real cap on bytes read is the request body limit (middleware.Payload). Set both.fh.Size lấy từ form multipart đã parse; giới hạn thực sự số byte đọc vào là giới hạn body của request (middleware.Payload). Hãy đặt cả hai.
2Sniffing is not a virus scanhttp.DetectContentType only reads magic bytes. It stops renamed HTML or scripts, not a malicious but valid image.http.DetectContentType chỉ đọc magic byte. Nó chặn HTML hay script bị đổi tên, không chặn một ảnh hợp lệ nhưng độc hại.
3Types must match exactlyText types come back with a charset ("text/plain; charset=utf-8"); list that full string in Types.Kiểu text trả về kèm charset ("text/plain; charset=utf-8"); ghi đủ chuỗi đó vào Types.
