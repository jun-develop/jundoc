Junkit · notification

notification

Turns "something went wrong in a request" into a readable Telegram alert — banner, request info, error location, a ready-to-run curl and an attached stack trace. Alerts go through a bounded background queue, so a slow or failing Telegram never delays a request.

Tự động chuyển lỗi trong request thành tin nhắn cảnh báo Telegram dễ đọc — gồm banner phân loại, thông tin request, vị trí file/dòng code gây lỗi, lệnh curl để tái hiện nhanh và file đính kèm stack trace. Cảnh báo đi qua một hàng đợi nền có giới hạn, nên Telegram chậm hay lỗi cũng không làm trễ request.

What it doesNó làm gì

Middleware (or your code) calls the Notifier; it formats Telegram HTML right away and queues the send. One worker delivers queued alerts in order; a failed send is logged, never returned.

Middleware (hoặc code ứng dụng) gọi Notifier; nó định dạng HTML Telegram ngay rồi đưa việc gửi vào hàng đợi. Một worker gửi lần lượt; gửi thất bại thì được log, không bao giờ trả về.

Use it in 30 secondsDùng ngay trong 30 giây

Panics are already covered by middleware.Recover. Call the Notifier yourself for errors you handle. Hover an explanation to light up its lines.

Panic đã được middleware.Recover lo. Tự gọi Notifier cho các lỗi bạn xử lý. Rê chuột vào giải thích để làm sáng các dòng tương ứng.

order_handler.go
type OrderHandler struct {
    service   OrderService // your own
    notifier  notification.Notifier
    responder response.Responder
}

func (h *OrderHandler) Create(c *gin.Context) {
    order, err := h.service.Create(c.Request.Context())
    if err != nil {
        _, file, line, _ := runtime.Caller(0)
        h.notifier.ReportError(c.Request.Context(), c.Request, notification.ErrorReport{
            Error:      err.Error(),
            Location:   file,
            Line:       line,
            Function:   "OrderHandler.Create",
            StatusCode: http.StatusBadGateway,
            ClientIP:   c.ClientIP(),
        })
        h.responder.Error(c, err)
        return
    }

    if order.Total > 10_000 {
        msg := "Big order <code>" + html.EscapeString(order.ID) + "</code>"
        h.notifier.Send(c.Request.Context(), notification.LevelWarning, msg)
    }

    h.responder.SendWithData(c, http.StatusCreated, "order_created", order)
}

interfaceNotifier
            

            

              
type Notifier interface {
	// Send queues msg, Telegram HTML under 4096 characters with request values escaped by the
	// caller, under a banner for level.
	Send(ctx context.Context, level Level, msg string)

	// ReportError queues a report of a failed request r, with a cURL repro whose secret headers
	// are masked and whose query and body are left out. ctx supplies the trace ID.
	ReportError(ctx context.Context, r *http.Request, report ErrorReport)
}

type Level int

const (
	LevelWarning Level = iota
	LevelError
)


            

            
No return values: both methods only queue the alert and return at once. Sends are best-effort;
              a full queue drops the alert.

            
Không có giá trị trả về: cả hai method chỉ đưa cảnh báo vào hàng đợi và trả về ngay. Việc gửi
              là best-effort; hàng đợi đầy thì cảnh báo bị bỏ.

ReportError(ctx context.Context, r *http.Request, report ErrorReport)

type ErrorReport struct {
	Error      string // the error or panic value as text
	Location   string // origin in the source
	Line       int
	Function   string
	Stack      string // when set, sent as a document after the message
	StatusCode int    // 5xx → error banner, else client-error banner
	ClientIP   string // r.RemoteAddr when empty
}


            

            
Does nothing unless Options.Enabled. Renders the alert below from
              r before queueing (r is not safe to read once the handler returns). The worker sends it with
              SendMessage; when Stack is non-empty it then sends a document
              stack-YYYYMMDD-HHMMSS.txt (content
              STACK TRACE\nGenerated: <time>\n----------------------------------------\n\n<stack>)
              with no caption.

            
Không làm gì trừ khi Options.Enabled. Dựng cảnh báo bên dưới từ r
              trước khi đưa vào hàng đợi (không được đọc r sau khi handler trả về). Worker gửi nó bằng
              SendMessage; khi Stack khác rỗng, nó gửi tiếp một tài liệu
              stack-YYYYMMDD-HHMMSS.txt (nội dung
              STACK TRACE\nGenerated: <time>\n----------------------------------------\n\n<stack>)
              không có caption.
