storage

Save an uploaded file and get back a public URL; delete it later by that URL — behind a two-method interface you can swap for S3 or GCS.

What it doesNó làm gì

The shipped LocalService writes into BaseDir under a fresh unique name and returns BaseURL + that name. Your router serves BaseDir at the same path.

LocalService có sẵn ghi vào BaseDir với một tên mới duy nhất và trả về BaseURL + tên đó. Router của bạn phục vụ BaseDir tại đúng đường dẫn ấy.

1 · handlerctx.FormFile(…)
Validate size and type, open the multipart file.
Kiểm tra kích thước và loại, mở file multipart.
2 · uploadUploadFile(ctx, f, name)
Keeps only the lowercased extension of name; refuses none or an active-content one (.html, .svg, .js…).
Chỉ giữ phần mở rộng (chữ thường) của name; từ chối khi không có hoặc là loại chạy được (.html, .svg, .js…).

Written to BaseDir, created at startup if missing.
Ghi vào BaseDir, thư mục được tạo lúc khởi động nếu chưa có.

You store BaseURL/<name> in the DB; Static("/uploads", BaseDir) serves it.

Use it in 30 secondsDùng ngay trong 30 giây

Replace a document's attachment safely — the same pattern Jungo uses for avatars. Hover an explanation to light up its lines.

Thay file đính kèm của một tài liệu một cách an toàn — đúng mẫu Jungo dùng cho avatar. Rê chuột vào giải thích để làm sáng các dòng tương ứng.

document_service.go
type DocumentService struct {
    repo    domain.DocumentRepository
    storage storage.Service
}

func (s *DocumentService) ReplaceFile(ctx context.Context, id uuid.UUID,
    file io.Reader, filename string) (string, error) {
    doc, err := s.repo.Get(ctx, id)
    if err != nil {
        return "", err
    }

    url, err := s.storage.UploadFile(ctx, file, filename)
    if err != nil {
        return "", err
    }

    if err := s.repo.SetFileURL(ctx, id, url); err != nil {
        _ = s.storage.DeleteFile(ctx, url) // undo the upload
        return "", err
    }

    if doc.FileURL != "" {
        _ = s.storage.DeleteFile(ctx, doc.FileURL) // drop the old file
    }

    return url, nil
}

typeLocalServicefuncNewLocalService
type LocalService struct { /* baseDir, baseURL — unexported */ }

func NewLocalService(opts Options) (*LocalService, error)
  • Runs os.MkdirAll(opts.BaseDir, os.ModePerm) immediately and trims a trailing / from opts.BaseURL.
  • Chạy os.MkdirAll(opts.BaseDir, os.ModePerm) ngay lập tức và cắt dấu / cuối của opts.BaseURL.
  • Error: storage: create base dir: <cause> (wrapped, use errors.Is / errors.As).
  • Lỗi: storage: create base dir: <cause> (được wrap, dùng errors.Is / errors.As).
  • Holds no lock and no open files — safe to share between goroutines.
  • Không giữ lock hay file nào mở — dùng chung giữa các goroutine an toàn.
method(*LocalService) UploadFile
func (s *LocalService) UploadFile(ctx context.Context, file io.Reader, originalFilename string) (string, error)
  • Stored name: <uuid v4>_<unix seconds><ext>, where ext is filepath.Ext(originalFilename) lowercased. Two uploads with the same name never collide.
  • Tên lưu: <uuid v4>_<unix giây><ext>, với ext là filepath.Ext(originalFilename) chuyển chữ thường. Hai lần upload cùng tên không bao giờ đụng nhau.
  • No extension, or one a browser could run when served back (.html .htm .xhtml .xht .shtml .svg .svgz .js .mjs .xml .xsl .xslt .swf) → ErrUnsafeExtension, nothing written.
  • Không có phần mở rộng, hoặc là loại trình duyệt có thể chạy khi phục vụ lại (.html .htm .xhtml .xht .shtml .svg .svgz .js .mjs .xml .xsl .xslt .swf) → ErrUnsafeExtension, không ghi gì.
  • Returns baseURL + "/" + name.
  • Trả về baseURL + "/" + name.
  • Errors: storage: create file: …, storage: copy file: …, storage: close file: …. On a copy or close error the partial file is removed.
  • Lỗi: storage: create file: …, storage: copy file: …, storage: close file: …. Khi copy hoặc close lỗi, file ghi dở được xoá.
  • ctx is checked before every read, so a cancelled request stops the copy (storage: copy file: context canceled) and the partial file is removed.
  • ctx được kiểm tra trước mỗi lần đọc, nên request bị huỷ sẽ dừng việc copy (storage: copy file: context canceled) và file ghi dở được xoá.
method(*LocalService) DeleteFile
func (s *LocalService) DeleteFile(_ context.Context, fileURL string) error
  • fileURL must be BaseURL + "/" + name; it removes BaseDir/<name>. Only a plain file name directly inside BaseDir is accepted, so the delete can never leave BaseDir.
  • fileURL phải là BaseURL + "/" + tên; nó xoá BaseDir/<tên>. Chỉ chấp nhận một tên file thuần nằm ngay trong BaseDir, nên lệnh xoá không bao giờ ra khỏi BaseDir.
  • A file that does not exist → nil.
  • File không tồn tại → nil.
  • A URL without the BaseURL + "/" prefix, or a name that is "", ".", ".." or contains / or \ → ErrInvalidURL. Any other removal failure → storage: delete file: ….
  • URL không có tiền tố BaseURL + "/", hoặc tên là "", ".", ".." hay chứa / hoặc \ → ErrInvalidURL. Lỗi xoá khác → storage: delete file: ….

var ErrInvalidFile = errors.New("upload: invalid file")

type Rule struct {
    MaxSize    int64    // largest allowed size in bytes
    Extensions []string // allowed lowercase extensions, with the dot
    Types      []string // allowed content types, as http.DetectContentType reports them
}

func Image(maxSize int64) Rule // JPEG, PNG, WebP
func Open(fh *multipart.FileHeader, rule Rule) (multipart.File, error)
func HasType(file io.ReadSeeker, types ...string) bool
func Extension(filename string) string

Checks an uploaded file before you hand it to UploadFile — storage itself only refuses active-content extensions and never looks at the bytes. Full page: upload.

Kiểm tra file upload trước khi đưa cho UploadFile — bản thân storage chỉ từ chối phần mở rộng chạy được và không xem nội dung byte. Trang đầy đủ: upload.

  • Open(fh, rule) refuses with ErrInvalidFile a file over rule.MaxSize, with an extension outside rule.Extensions (compared lower-cased), or whose first 512 bytes are not one of rule.Types (e.g. HTML or PHP renamed to .png). It then rewinds the file so the whole of it is stored. The caller closes it. Failing to open the upload is a wrapped I/O error, not ErrInvalidFile.
  • Open(fh, rule) từ chối bằng ErrInvalidFile file lớn hơn rule.MaxSize, có phần mở rộng ngoài rule.Extensions (so sánh dạng chữ thường), hoặc có 512 byte đầu không thuộc rule.Types (vd. file HTML hay PHP đổi tên thành .png). Sau đó nó tua lại đầu file để lưu được trọn vẹn. Bên gọi tự đóng file. Không mở được file upload là lỗi I/O được wrap, không phải ErrInvalidFile.
  • Image(maxSize) is the rule for JPEG, PNG and WebP. For another kind of file (PDF, CSV…) write your own Rule.
  • Image(maxSize) là rule cho JPEG, PNG và WebP. Loại file khác (PDF, CSV…) thì tự viết Rule.
  • HasType and Extension are the content and extension checks on their own.
  • HasType và Extension là hai bước kiểm tra nội dung và phần mở rộng dùng riêng lẻ.

Good to knowCần lưu ý

1No content checksUploadFile only refuses missing and active-content extensions (HTML, SVG, scripts — stored XSS on the API origin); it stores any bytes under any other extension. Files under /uploads are public, so allow-list extensions, cap the size and check the first bytes before calling it (upload.Open does all three).UploadFile chỉ từ chối khi không có phần mở rộng hoặc là loại chạy được (HTML, SVG, script — stored XSS trên origin của API); với phần mở rộng khác nó lưu mọi loại byte. File trong /uploads là công khai, nên hãy giới hạn phần mở rộng theo danh sách cho phép, giới hạn kích thước và kiểm tra các byte đầu trước khi gọi (upload.Open làm cả ba).
2Body limit comes firstIn Jungo the global Payload middleware caps every body at SECURITY_MAX_BODY_SIZE (default 2097152 = 2 MiB) and answers 413 request_body_too_large — before your handler's file-size check runs. An upload route that needs more declares it through router.BodyLimited, as the avatar route does: 5 MB file + 64 KiB for multipart boundaries and headers. Keep the two numbers in step.Trong Jungo, middleware Payload global giới hạn mọi body ở SECURITY_MAX_BODY_SIZE (mặc định 2097152 = 2 MiB) và trả 413 request_body_too_large — trước khi đoạn kiểm tra kích thước file trong handler kịp chạy. Route upload cần lớn hơn thì khai báo qua router.BodyLimited, như route avatar: file 5 MB + 64 KiB cho boundary và header của multipart. Giữ hai con số này khớp nhau.
3Half-written files are removedIf io.Copy fails midway or the final Close fails, UploadFile removes the partial file and returns the error.Nếu io.Copy lỗi giữa chừng hoặc lần Close cuối lỗi, UploadFile xoá file ghi dở và trả lỗi.
4Full URLs are storedThe DB keeps BaseURL/<name>. Changing STORAGE_BASE_URL later does not rewrite old rows, and DeleteFile then refuses those old URLs with ErrInvalidURL — migrate the rows when you change it.DB lưu BaseURL/<name>. Đổi STORAGE_BASE_URL sau này không sửa các dòng cũ, và DeleteFile khi đó từ chối các URL cũ với ErrInvalidURL — hãy cập nhật các dòng khi đổi.
5DeleteFile checks the prefixOnly BaseURL + "/" + name deletes; anything else is ErrInvalidURL. Any such URL still deletes that file, so only pass URLs you stored yourself.Chỉ BaseURL + "/" + tên mới xoá được; còn lại là ErrInvalidURL. URL đúng dạng đó vẫn xoá được file tương ứng, nên chỉ truyền URL do chính bạn lưu.
6Trailing slashA trailing / on BaseURL is trimmed, so …/uploads/ and …/uploads give the same URLs.Dấu / cuối của BaseURL bị cắt, nên …/uploads/ và …/uploads cho ra cùng URL.
7Local disk onlyWith several replicas each has its own BaseDir — use a shared volume or write another Service (S3, GCS).Chạy nhiều replica thì mỗi cái có BaseDir riêng — hãy dùng volume chung hoặc viết một Service khác (S3, GCS).
8Errors hidden in JungoUserService.UploadAvatar turns any storage error (e.g. disk full) into ErrInvalidAvatarFile, so a server problem shows up as a 400 for the client.UserService.UploadAvatar biến mọi lỗi storage (vd. đầy đĩa) thành ErrInvalidAvatarFile, nên lỗi phía server lại hiện ra như lỗi 400 của client.
