storage

Save an uploaded file and get back a public URL; delete it later by that URL — behind a two-method interface you can swap for S3 or GCS.

Lưu file upload và nhận lại một URL công khai; sau này xoá file bằng chính URL đó — sau một interface hai method mà bạn có thể thay bằng S3 hay GCS.

What it doesNó làm gì

The shipped LocalService writes into BaseDir under a fresh unique name and returns BaseURL + that name. Your router serves BaseDir at the same path.

LocalService có sẵn ghi vào BaseDir với một tên mới duy nhất và trả về BaseURL + tên đó. Router của bạn phục vụ BaseDir tại đúng đường dẫn ấy.

1 · handlerctx.FormFile(…)
Validate size and type, open the multipart file.
Kiểm tra kích thước và loại, mở file multipart.
2 · uploadUploadFile(ctx, f, name)
Keeps only the extension of name.
Chỉ giữ lại phần mở rộng của name.
3 · disk<uuid>_<unix>.png
Written to BaseDir, created at startup if missing.
Ghi vào BaseDir, thư mục được tạo lúc khởi động nếu chưa có.
4 · serveGET /uploads/…
You store BaseURL/<name> in the DB; Static("/uploads", BaseDir) serves it.
Bạn lưu BaseURL/<name> vào DB; Static("/uploads", BaseDir) phục vụ nó.

Use it in 30 secondsDùng ngay trong 30 giây

Replace a document's attachment safely — the same pattern Jungo uses for avatars. Hover an explanation to light up its lines.

Thay file đính kèm của một tài liệu một cách an toàn — đúng mẫu Jungo dùng cho avatar. Rê chuột vào giải thích để làm sáng các dòng tương ứng.

document_service.go
type DocumentService struct {
    repo    domain.DocumentRepository
    storage storage.Service
}

func (s *DocumentService) ReplaceFile(ctx context.Context, id uuid.UUID,
    file io.Reader, filename string) (string, error) {
    doc, err := s.repo.Get(ctx, id)
    if err != nil {
        return "", err
    }

    url, err := s.storage.UploadFile(ctx, file, filename)
    if err != nil {
        return "", err
    }

    if err := s.repo.SetFileURL(ctx, id, url); err != nil {
        _ = s.storage.DeleteFile(ctx, url) // undo the upload
        return "", err
    }

    if doc.FileURL != "" {
        _ = s.storage.DeleteFile(ctx, doc.FileURL) // drop the old file
    }

    return url, nil
}

API referenceTham chiếu API

Everything the package exports — signatures copied from junkit/storage/*.go.

Mọi thứ package export — chữ ký chép từ junkit/storage/*.go.

interfaceService 
type Service interface {
    UploadFile(ctx context.Context, file io.Reader, originalFilename string) (string, error)
    DeleteFile(ctx context.Context, fileURL string) error
}
  • UploadFile stores file and returns its URL (or path).
  • UploadFile lưu file và trả về URL (hoặc đường dẫn) của nó.
  • DeleteFile removes a file given the URL UploadFile returned.
  • DeleteFile xoá file dựa trên URL mà UploadFile đã trả.

type Options struct {

    BaseURL string

typeLocalServicefuncNewLocalService
type LocalService struct { /* baseDir, baseURL — unexported */ }

func NewLocalService(baseDir, baseURL string) (*LocalService, error)
  • Runs os.MkdirAll(baseDir, os.ModePerm) immediately.
  • Chạy os.MkdirAll(baseDir, os.ModePerm) ngay lập tức.
  • Error: create storage directory "<baseDir>": <cause> (wrapped, use errors.Is / errors.As).
  • Lỗi: create storage directory "<baseDir>": <cause> (được wrap, dùng errors.Is / errors.As).
  • Holds no lock and no open files — safe to share between goroutines.
  • Không giữ lock hay file nào mở — dùng chung giữa các goroutine an toàn.
method(*LocalService) UploadFile
func (s *LocalService) UploadFile(_ context.Context, file io.Reader, originalFilename string) (string, error)
  • Stored name: <uuid v4>_<unix seconds><ext>, where ext = filepath.Ext(originalFilename) kept exactly (case included; no extension → no suffix). Two uploads with the same name never collide.
  • Tên lưu: <uuid v4>_<unix giây><ext>, với ext = filepath.Ext(originalFilename) giữ nguyên (kể cả hoa/thường; không có phần mở rộng → không có hậu tố). Hai lần upload cùng tên không bao giờ đụng nhau.
  • Returns baseURL + "/" + name.
  • Trả về baseURL + "/" + name.
  • Errors: create destination file: …, copy file contents: ….
  • Lỗi: create destination file: …, copy file contents: ….
  • ctx is ignored; the copy runs until the reader is drained.
  • ctx bị bỏ qua; việc copy chạy tới khi đọc hết reader.
method(*LocalService) DeleteFile
func (s *LocalService) DeleteFile(_ context.Context, fileURL string) error
  • Takes filepath.Base(fileURL) and removes baseDir/<that name>. Only the last path segment counts, so the delete can never leave BaseDir.
  • Lấy filepath.Base(fileURL) rồi xoá baseDir/<tên đó>. Chỉ đoạn cuối của đường dẫn được dùng, nên lệnh xoá không bao giờ ra khỏi BaseDir.
  • A file that does not exist → nil.
  • File không tồn tại → nil.
  • "", ".", "/" → invalid file URL: <fileURL>. Any other removal failure → delete file: ….
  • "", ".", "/" → invalid file URL: <fileURL>. Lỗi xoá khác → delete file: ….

Good to knowCần lưu ý

1No content checksThe package stores any bytes under any extension. Validate size, extension and ideally the real content type before calling UploadFile — files under /uploads are public.Package lưu mọi loại byte với mọi phần mở rộng. Hãy kiểm tra kích thước, phần mở rộng và tốt nhất là content type thật trước khi gọi UploadFile — file trong /uploads là công khai.
2Body limit comes firstIn Jungo the Payload middleware caps every body at SECURITY_MAX_BODY_SIZE (default 2097152 = 2 MiB) and answers 413 request_body_too_large, so the 5 MB avatar limit is never reached unless you raise it.Trong Jungo, middleware Payload giới hạn mọi body ở SECURITY_MAX_BODY_SIZE (mặc định 2097152 = 2 MiB) và trả 413 request_body_too_large, nên giới hạn avatar 5 MB không bao giờ chạm tới trừ khi bạn tăng giá trị này.
3Half-written files stayIf io.Copy fails midway, UploadFile returns an error but does not remove the partial file.Nếu io.Copy lỗi giữa chừng, UploadFile trả lỗi nhưng không xoá file đang ghi dở.
4Full URLs are storedThe DB keeps BaseURL/<name>. Changing STORAGE_BASE_URL later does not rewrite old rows. Deleting still works because only the file name is used.DB lưu BaseURL/<name>. Đổi STORAGE_BASE_URL sau này không sửa các dòng cũ. Xoá vẫn chạy vì chỉ dùng tên file.
5DeleteFile trusts the nameAny string whose last segment matches a file in BaseDir deletes it — the URL's host or prefix is not checked. Only pass URLs you stored yourself.Bất kỳ chuỗi nào có đoạn cuối trùng tên một file trong BaseDir đều xoá được file đó — host hay tiền tố của URL không được kiểm tra. Chỉ truyền URL do chính bạn lưu.
6Trailing slashBaseURL ending in / produces …/uploads//<name>.BaseURL kết thúc bằng / sẽ cho ra …/uploads//<name>.
7Local disk onlyWith several replicas each has its own BaseDir — use a shared volume or write another Service (S3, GCS).Chạy nhiều replica thì mỗi cái có BaseDir riêng — hãy dùng volume chung hoặc viết một Service khác (S3, GCS).
8Errors hidden in JungoUserService.UploadAvatar turns any storage error (e.g. disk full) into ErrInvalidAvatarFile, so a server problem shows up as a 400 for the client.UserService.UploadAvatar biến mọi lỗi storage (vd. đầy đĩa) thành ErrInvalidAvatarFile, nên lỗi phía server lại hiện ra như lỗi 400 của client.
