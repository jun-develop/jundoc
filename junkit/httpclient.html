httpclient

A standard *http.Client with sane timeouts and connection pooling, plus optional automatic retries (network errors, 429, 5xx) with exponential backoff and jitter.

Một *http.Client chuẩn với timeout và connection pool hợp lý, kèm tuỳ chọn tự retry (lỗi mạng, 429, 5xx) với backoff luỹ thừa và jitter.

What it doesNó làm gì

You get a plain *http.Client — use it like any other. When MaxRetries > 0, a retry layer sits between the client and the real transport.

Bạn nhận một *http.Client bình thường — dùng như mọi client khác. Khi MaxRetries > 0, một lớp retry nằm giữa client và transport thật.

1 · your codeclient.Do(req)
Timeout (15s) bounds the whole call, retries and waits included.
Timeout (15s) giới hạn cả lần gọi, tính luôn retry và thời gian chờ.
2 · retry (optional)retryTransport
Buffers the body; on error / 429 / 5xx waits and tries again, up to MaxRetries times.
Đệm body; gặp lỗi / 429 / 5xx thì chờ rồi thử lại, tối đa MaxRetries lần.
3 · transport*http.Transport
Pooled keep-alive connections, dial / TLS / header timeouts, HTTP/2, proxy from env.
Kết nối keep-alive trong pool, timeout dial / TLS / header, HTTP/2, proxy từ biến môi trường.
4 · server200 · 4xx · 429 · 5xx
Only 429 and ≥ 500 (and network errors) trigger a retry; every other status returns at once.
Chỉ 429 và ≥ 500 (cùng lỗi mạng) mới gây retry; mọi status khác trả về ngay.

Wire it upKết nối vào app

Jungo provides the defaults-only client directly; the Module is the way to pass your own Options.

Jungo cung cấp thẳng client dùng toàn mặc định; Module là cách để truyền Options của riêng bạn.

internal/app/fx.go
// in CoreModules(cfg):
fx.Provide(httpclient.NewDefaultClient),

Puts one shared *http.Client in the graph with every default and no retries (MaxRetries is 0). Jungo does not use httpclient.Module.

Đưa một *http.Client dùng chung vào graph với toàn bộ mặc định và không retry (MaxRetries bằng 0). Jungo không dùng httpclient.Module.

fx.go
fx.Supply(httpclient.Options{MaxRetries: 2}),
httpclient.Module, // provides *http.Client

Use one or the other — providing *http.Client twice makes Fx fail at startup.

Chỉ dùng một trong hai cách — cung cấp *http.Client hai lần sẽ làm Fx lỗi khi khởi động.

main.go
client := httpclient.NewClient(httpclient.Options{MaxRetries: 3, Timeout: 5 * time.Second})

plain := httpclient.NewDefaultClient() // same as NewClient(httpclient.Options{})

Build it once and reuse it: the connection pool lives in the client's transport.

Tạo một lần rồi dùng lại: connection pool nằm trong transport của client.

Use it in 30 secondsDùng ngay trong 30 giây

An API client with a 5s budget and two retries. Hover an explanation to light up its lines.

Một API client với ngân sách 5s và hai lần retry. Rê chuột vào giải thích để làm sáng các dòng tương ứng.

geo_client.go
type GeoClient struct {
    http *http.Client
}

func NewGeoClient() *GeoClient {
    return &GeoClient{http: httpclient.NewClient(httpclient.Options{
        Timeout:    5 * time.Second,
        MaxRetries: 2,
    })}
}

func (c *GeoClient) Lookup(ctx context.Context, ip string) (*Geo, error) {
    req, err := http.NewRequestWithContext(ctx, http.MethodGet,
        "https://geo.example.com/"+ip, nil)
    if err != nil {
        return nil, err
    }
    resp, err := c.http.Do(req)
    if err != nil {
        return nil, err
    }
    defer resp.Body.Close()
    if resp.StatusCode != http.StatusOK {
        return nil, fmt.Errorf("geo: status %d", resp.StatusCode)
    }
    var g Geo
    return &g, json.NewDecoder(resp.Body).Decode(&g)
}

Try it: the backoff scheduleThử ngay: lịch backoff

Same formula as retryTransport.backoff: wait = RetryWaitMin << n, capped at RetryWaitMax, plus a random jitter of 0–20%.

Công thức thời gian chờ lũy tiến (Exponential Backoff): wait = RetryWaitMin × 2ⁿ, giới hạn tối đa tại RetryWaitMax, kèm độ lệch ngẫu nhiên (jitter) 0–20%.

Values ≤ 0 fall back to the defaults, exactly like NewClient. The total ignores the time the requests themselves take.

Giá trị ≤ 0 quay về mặc định, đúng như NewClient. Tổng chưa tính thời gian chính các request chạy.
