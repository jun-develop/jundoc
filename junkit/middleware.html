What it doesNó làm gì

Eleven gin.HandlerFuncs that protect and instrument every request: code before c.Next() runs on the way in, code after it on the way out. Press ▶ to follow one request through the recommended order.

Mười một gin.HandlerFunc bảo vệ và đo đạc mọi request: code trước c.Next() chạy lúc đi vào, code sau nó chạy lúc đi ra. Bấm ▶ để theo một request qua thứ tự khuyến nghị.

Authentication and permissions are not here: they are app policy and run after this chain, per route group. In Jungo they live in internal/middleware — see Jungo · auth and Jungo · permissions & roles. This package gives them SetIdentity.

Xác thực và phân quyền không nằm ở đây: chúng là chính sách của app và chạy sau chuỗi này, theo từng route group. Ở Jungo chúng nằm trong internal/middleware — xem Jungo · auth và Jungo · phân quyền. Package này cung cấp cho chúng SetIdentity.

SetupCài đặt

There is no Fx module: call the constructors where you build the router, with r.Use(…) in this order (the first runs outermost). Jungo's own chain, with its config, is on Jungo · request flow.

Không có Fx module: gọi constructor ngay chỗ tạo router, bằng r.Use(…) theo thứ tự này (cái đầu tiên ở ngoài cùng). Chuỗi của chính Jungo, cùng cấu hình, nằm ở Jungo · luồng request.

Every constructor that answers (Payload, Limiter, Banner, Recover, RoutePatterns) needs a response.Responder; Banner and Limiter key clients by c.ClientIP(), so set the engine's trusted proxies (see Good to know). Invalid static options panic at construction, not per request.

main.go
func main() {
    log := zap.NewExample()
    responder := response.NewResponder(i18n.NewTranslator())
    debug := middleware.TracerDebugOptions{QueryKey: "t_debug", QueryValue: "change-me",
        SecretHeader: "X-Internal-Secret", Secret: "change-me-secret"}

    r := gin.New()
    _ = r.SetTrustedProxies(nil) // ClientIP() = the TCP peer address
    r.Use(
        middleware.TracerDebug(debug),
        middleware.Security(middleware.SecurityOptions{}),
        middleware.Trace(middleware.TraceOptions{Version: "v1.0.0", Environment: "development"}),
        middleware.CORS(middleware.CORSOptions{
            AllowOrigins: []string{"http://localhost:3000"},
            AllowMethods: []string{"GET", "POST", "OPTIONS"},
            AllowHeaders: []string{"Authorization", "Content-Type"},
            MaxAge:       600,
        }),
        middleware.AccessLog(middleware.AccessLogOptions{}, log),
        middleware.Recover(middleware.RecoverOptions{Debug: debug}, log, nil, responder),
        middleware.Limiter(middleware.LimiterOptions{RequestsPerSecond: 10, Burst: 30}, log, responder, nil),
        middleware.Payload(middleware.PayloadOptions{MaxBodySize: 2 << 20}, responder),
    )

    r.POST("/echo", func(c *gin.Context) {
        responder.SendWithData(c, http.StatusOK, "operation_successful", middleware.GetPayload(c))
    })

    _ = r.Run(":" + os.Getenv("API_SERVER_PORT"))
}

Turns on the tracer dashboard for requests whose query has ?<QueryKey>=<QueryValue> and whose SecretHeader header equals Secret. Otherwise it just calls c.Next().

Bật dashboard tracer cho request có query ?<QueryKey>=<QueryValue> và header SecretHeader bằng Secret. Ngược lại chỉ gọi c.Next().

  • Matches(c) is that check (the secret is compared in constant time). Pass it as AccessLogOptions.SkipIf and the same options as RecoverOptions.Debug.
  • Matches(c) chính là phép kiểm tra đó (secret được so sánh constant-time). Truyền nó làm AccessLogOptions.SkipIf và truyền cùng options làm RecoverOptions.Debug.
  • Disabled when any field is empty.
  • Tắt khi có bất kỳ field nào rỗng.
  • When active: puts a fresh tracer into the request context and swaps c.Writer for one that discards the body the handler writes. The handler still runs for real (database writes happen).
  • Khi bật: đặt một tracer mới vào request context và thay c.Writer bằng writer bỏ đi body mà handler ghi. Handler vẫn chạy thật (ghi database vẫn xảy ra).
  • Afterwards it always answers 200 with Cache-Control: no-cache, no-store, must-revalidate, Pragma: no-cache, Expires: 0.
  • Sau đó luôn trả 200 kèm Cache-Control: no-cache, no-store, must-revalidate, Pragma: no-cache, Expires: 0.
  • Body: if the User-Agent contains curl, httpie or wget (case-insensitive) → application/json; charset=utf-8; otherwise → text/html; charset=utf-8 (the interactive dashboard).
  • Body: nếu User-Agent chứa curl, httpie hoặc wget (không phân biệt hoa thường) → application/json; charset=utf-8; ngược lại → text/html; charset=utf-8 (dashboard tương tác).
  • A tracer.BreakpointSignal panic (from tracer.Stop()) is caught and the dashboard notes "⏸ Stopped by tracer.Stop() after …". Any other panic is re-panicked.
  • Panic tracer.BreakpointSignal (từ tracer.Stop()) được bắt và dashboard ghi "⏸ Stopped by tracer.Stop() after …". Panic khác được panic lại.

func Trace(opts TraceOptions) gin.HandlerFunc
  • Generates uuid.NewString(). Only with TrustHeader does it reuse the incoming X-Trace-Id request header, and only if it is 1–64 letters, digits, - or _ (anything else is replaced), so a client's value is safe in logs, headers and alerts.
  • Sinh uuid.NewString(). Chỉ khi bật TrustHeader nó mới dùng lại header request X-Trace-Id, và chỉ khi header dài 1–64 ký tự gồm chữ, số, - hoặc _ (khác đi thì bị thay), nên giá trị do client gửi luôn an toàn trong log, header và cảnh báo.
  • Puts it in the request context with logger.WithTraceID (read it back with logger.GetTraceID(ctx)) and sets the response header X-Trace-Id.
  • Đưa nó vào request context bằng logger.WithTraceID (đọc lại bằng logger.GetTraceID(ctx)) và đặt header response X-Trace-Id.
  • Stores in the Gin context: response.StartTimeContextKey (time.Now()), response.VersionContextKey, response.EnvContextKey — with the trace ID from the request context, the responder turns these into api_info.{trace_id, latency, version, env}. Also stores the commit under the private key "api_commit".
  • Lưu vào Gin context: response.StartTimeContextKey (time.Now()), response.VersionContextKey, response.EnvContextKey — cùng trace ID trong request context, responder biến chúng thành api_info.{trace_id, latency, version, env}. Commit được lưu dưới key riêng "api_commit".
  • Never aborts.
  • Không bao giờ abort.

funcCORScors.go
func CORS(opts CORSOptions) gin.HandlerFunc
  • If the request has an Origin that is allowed (listed, or the list contains "*"):
    • "*" → Access-Control-Allow-Origin: *
    • otherwise → Access-Control-Allow-Origin: <the request's Origin>
    • AllowCredentials → Access-Control-Allow-Credentials: true
  • Nếu request có Origin được phép (có trong danh sách, hoặc danh sách chứa "*"):
    • "*" → Access-Control-Allow-Origin: *
    • ngược lại → Access-Control-Allow-Origin: <Origin của request>
    • AllowCredentials → Access-Control-Allow-Credentials: true
  • Panics at setup when AllowOrigins holds "*" together with AllowCredentials, which would let any site make credentialed requests.
  • Panic lúc khởi tạo khi AllowOrigins chứa "*" cùng với AllowCredentials, vì như vậy site nào cũng gửi được request kèm credentials.
  • A disallowed origin is not rejected — it just gets no allow-origin header, so the browser hides the response.
  • Origin không được phép không bị từ chối — nó chỉ không có header allow-origin, nên trình duyệt giấu response.
  • Always adds Vary: Origin (with Header().Add, so it sits beside Gzip's Vary: Accept-Encoding), even when Origin is missing or not allowed, so shared caches key on it.
  • Luôn thêm Vary: Origin (bằng Header().Add, nên nằm cạnh Vary: Accept-Encoding của Gzip), kể cả khi không có Origin hoặc origin không được phép, để cache dùng chung phân biệt theo nó.
  • Always sets Access-Control-Allow-Headers, Access-Control-Allow-Methods (lists joined with ", ") and Access-Control-Max-Age, on every response.
  • Luôn đặt Access-Control-Allow-Headers, Access-Control-Allow-Methods (danh sách nối bằng ", ") và Access-Control-Max-Age cho mọi response.
  • Every OPTIONS request is aborted with 204 (empty body) — the route handler is never reached.
  • Mọi request OPTIONS bị abort với 204 (body rỗng) — không bao giờ tới handler của route.

func Banner(opts BannerOptions, logger *zap.Logger, responder response.Responder, notifier notification.Notifier) gin.HandlerFunc

Bans clients that probe the API for weak spots. Limiter counts how many requests a client sends; Banner looks at what they ask for, so it also catches a slow scanner that never reaches the rate limit. The client is security.ClientKey(c.ClientIP()), like Limiter.

Ban client đang dò tìm lỗ hổng của API. Limiter đếm bao nhiêu request một client gửi; Banner nhìn vào cái gì họ gọi, nên bắt được cả kẻ quét chậm không bao giờ chạm ngưỡng rate limit. Client là security.ClientKey(c.ClientIP()), giống Limiter.

  • Banned → 403 FORBIDDEN / access_denied "Access denied due to suspicious activity or IP restriction" with Retry-After (seconds left), then abort.
  • Panics at setup without Cache, a positive MaxStrikes and StrikeWindow, or BanDurations.
  • Đang bị ban → 403 FORBIDDEN / access_denied "Access denied due to suspicious activity or IP restriction" kèm Retry-After (số giây còn lại), rồi abort.
  • Panic lúc khởi tạo nếu thiếu Cache, MaxStrikes và StrikeWindow dương, hoặc BanDurations.
  • Instant ban on the first request when ScannerAgents match the User-Agent, or — only for a request that matched no route — TrapPaths match the path or AttackPatterns the path plus URL-decoded query. Real routes are never checked against them: their queries carry user input such as search terms. The defaults hold only signs no real client sends; anything vaguer is left to strikes, since an unknown path still answers 404.
  • Ban ngay từ request đầu tiên khi ScannerAgents khớp với User-Agent, hoặc — chỉ với request không trúng route nào — TrapPaths khớp với path hay AttackPatterns khớp với path cộng query đã URL-decode. Route thật không bao giờ bị kiểm tra bằng chúng: query của route thật chứa dữ liệu người dùng như từ khoá tìm kiếm. Mặc định chỉ chứa dấu hiệu mà client thật không bao giờ gửi; cái gì mơ hồ hơn để bộ đếm strike lo, vì đường dẫn lạ vẫn trả 404.
  • Embedded requests: a browser's cross-site no-cors request (Sec-Fetch-Site: cross-site + Sec-Fetch-Mode: no-cors, e.g. an <img> another site embeds) never bans or strikes — only its User-Agent is checked — so a third-party page cannot get its visitors banned.
  • Request bị nhúng: request no-cors khác site của trình duyệt (Sec-Fetch-Site: cross-site + Sec-Fetch-Mode: no-cors, vd. thẻ <img> mà site khác nhúng) không bao giờ bị ban hay tính strike — chỉ User-Agent được kiểm tra — nên trang bên thứ ba không thể khiến khách của nó bị ban.
  • Cost: patterns see lowercased input and each starts with a literal, which Go's regexp finds with a plain substring search before running its matcher — cheaper than one large alternation. Requests that matched a route skip the path and query checks entirely. Keep custom patterns starting with a literal too.
  • Chi phí: pattern nhận chuỗi đã viết thường và mỗi pattern bắt đầu bằng chữ cố định, để regexp của Go tìm chuỗi con trước khi chạy bộ khớp — rẻ hơn một regex lớn gồm nhiều nhánh |. Request đã khớp route bỏ qua hẳn phần kiểm tra path và query. Pattern tự thêm cũng nên bắt đầu bằng chữ cố định.
  • Strikes: after the handler, a status in StrikeStatuses adds a strike; the MaxStrikes-th strike within StrikeWindow bans. The request that hits the limit still gets its normal answer; the ban applies from the next one.
  • Strike: sau handler, status nằm trong StrikeStatuses được tính một strike; strike thứ MaxStrikes trong StrikeWindow sẽ ban. Request chạm ngưỡng vẫn nhận response bình thường; lệnh ban có hiệu lực từ request kế tiếp.
  • Escalation: the 1st ban lasts BanDurations[0], the 2nd BanDurations[1], … the last one repeats. The ban count is forgotten twice the longest duration after the first ban.
  • Tăng dần: lần ban thứ 1 kéo dài BanDurations[0], lần 2 BanDurations[1], … mục cuối được lặp lại. Số lần ban được quên sau gấp đôi thời lượng dài nhất kể từ lần ban đầu.
  • Once per ban: logger.Warn("middleware: client banned") with ip, blocked (the key), reason, path, duration, and — if notifier != nil — a queued alert "⛔ Client Banned" (notifier.Send(ctx, notification.LevelError, …)). Requests refused during a ban are not logged by Banner (AccessLog still logs them).
  • Mỗi lần ban một lần: logger.Warn("middleware: client banned") với ip, blocked (key), reason, path, duration, và — nếu notifier != nil — một cảnh báo "⛔ Client Banned" được đưa vào hàng đợi (notifier.Send(ctx, notification.LevelError, …)). Request bị từ chối trong lúc ban không được Banner ghi log (AccessLog vẫn ghi).
  • A cache error never blocks anyone: a failed strike count is logged and the request goes on.
  • Lỗi cache không bao giờ chặn nhầm ai: đếm strike thất bại thì ghi log và request đi tiếp.

A token bucket (golang.org/x/time/rate) per client, kept in memory. The client is security.ClientKey(c.ClientIP()): an IPv4 address, or an IPv6 address's whole /64 block, so rotating addresses inside it does not get a fresh bucket. Một token bucket (golang.org/x/time/rate) cho mỗi client, lưu trong bộ nhớ. Client là security.ClientKey(c.ClientIP()): một địa chỉ IPv4, hoặc cả khối /64 của địa chỉ IPv6, nên đổi địa chỉ trong khối đó không được bucket mới. Whitelist vẫn so với đúng IP gốc. Không có goroutine nền: client không hoạt động được dọn kiểu lười, bởi request kế tiếp chạm tới shard của nó.

  • Được bỏ qua: chỉ IP có trong IPWhitelist. Không thứ gì client tự gửi (như User-Agent) giúp bỏ qua giới hạn.
  • Bucket empty → 429 TOO_MANY_REQUESTS / too_many_requests "Too many requests. Please try again later.", then abort.
  • Hết token → 429 TOO_MANY_REQUESTS / too_many_requests "Too many requests. Please try again later.", rồi abort.
