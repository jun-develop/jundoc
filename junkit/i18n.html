Junkit · i18n

i18n

Turns message keys like "user_not_found" into text in the right language, with a safe fallback: requested language → default language → the key itself.

Biến các key thông điệp như "user_not_found" thành văn bản đúng ngôn ngữ, với cơ chế dự phòng an toàn: ngôn ngữ được yêu cầu → ngôn ngữ mặc định → chính cái key.

1

What it doesNó làm gì

One shared Translator holds a map language → key → message. Features add their keys at start-up; response and validation look them up on every request.

Một Translator dùng chung giữ map ngôn ngữ → key → thông điệp. Các feature thêm key của mình lúc khởi động; response và validation tra cứu chúng ở mỗi request.

1 · fillAddTranslations
Built-in English catalog + each feature's registerTranslations. Later calls overwrite keys.
Catalog tiếng Anh có sẵn + registerTranslations của từng feature. Lần gọi sau ghi đè key.
2 · store*Translator
Thread-safe (sync.RWMutex); default language "en".
An toàn đa luồng (sync.RWMutex); ngôn ngữ mặc định "en".
3 · resolveGetMessage
lang (or default if empty) → default language → key. Applies fmt.Sprintf only if args were given and the text has a %.
lang (hoặc mặc định nếu rỗng) → ngôn ngữ mặc định → key. Chỉ gọi fmt.Sprintf khi có args và văn bản chứa %.
4 · use"message": "…"
response.Responder fills the JSON message; validation.Validator builds field errors.
response.Responder điền message trong JSON; validation.Validator tạo lỗi cho từng field.

order/module.go
func registerTranslations(t *i18n.Translator) {
    t.AddTranslations(map[string]map[string]string{
        i18n.LangEN: {
            "order_missing": "Order not found",
            "order_total":   "Total of %[1]s: %[2]s",
        },
        i18n.LangVI: {
            "order_missing": "Không thấy đơn hàng",
        },
    })
}

// fx.New(i18n.Module, fx.Invoke(registerTranslations), …)

func demo(t *i18n.Translator) {
    // "Không thấy đơn hàng"
    t.GetMessage("order_missing", i18n.LangVI)
    // "Total of A-17: 42" (taken from en)
    t.GetMessage("order_total", i18n.LangVI, "A-17", "42")
    // "email is required" (built-in catalog)
    t.GetMessage("required", "", "email")
    // "no_such_key"
    t.GetMessage("no_such_key", i18n.LangEN)
}

constLangEN · LangVI
            

            

              
const (
    LangEN = "en"
    LangVI = "vi"
)


            

            
Language codes. Only LangEN has a built-in catalog; LangVI is just a
              constant until you add Vietnamese messages. Any other string works as a language code too.

            
Mã ngôn ngữ. Chỉ LangEN có catalog sẵn; LangVI chỉ là một hằng số cho
              tới khi bạn thêm thông điệp tiếng Việt. Chuỗi bất kỳ khác cũng dùng được làm mã ngôn ngữ.

          

          

            
typeTranslator

            

              
type Translator struct {
    // contains unexported fields: a sync.RWMutex,
    // translations map[string]map[string]string and defaultLang
}


            

            
Holds the catalogs. No exported fields — always create it with NewTranslator (the
              zero value has a nil map and panics on AddTranslations). Share one instance; it is safe for
              concurrent reads and writes.

            
Giữ các catalog. Không có field export — luôn tạo bằng NewTranslator (giá trị zero
              có map nil và sẽ panic khi AddTranslations). Dùng chung một instance; an toàn khi đọc và ghi
              đồng thời.

MethodsMethod

        

          

            
method(*Translator)
                AddTranslations

            

              
func (t *Translator) AddTranslations(translations map[string]map[string]string)

            

            
Merges language → key → message into the catalogs. New languages are created;
              existing keys are overwritten; keys not in the call are kept (an en-only update leaves
              vi untouched). Use it to override built-in English texts too.

            
Gộp ngôn ngữ → key → thông điệp vào catalog. Ngôn ngữ mới được tạo; key đã có bị
              ghi đè; key không có trong lần gọi được giữ nguyên (cập nhật chỉ en không ảnh hưởng
              vi). Dùng cách này để ghi đè cả văn bản tiếng Anh có sẵn.

          

          

            
method(*Translator)
                GetMessage

            

              
func (t *Translator) GetMessage(key string, lang string, args ...any) string

            

            
    
              
  1. lang == "" → use the default language.
    2. 
              
  2. lang == "" → dùng ngôn ngữ mặc định.
    3. 
              
  3. Look up key in that language; if missing (and it isn't the default), look in
                the default language.
    4. 
              
  4. Tìm key trong ngôn ngữ đó; nếu không có (và đó không phải ngôn ngữ mặc định),
                tìm trong ngôn ngữ mặc định.
    5. 
              
  5. Still missing → return key unchanged (args ignored).
    6. 
              
  6. Vẫn không có → trả nguyên key (bỏ qua args).
    7. 
              
  7. Found → fmt.Sprintf(message, args...) if len(args) > 0 and the
                message contains %; otherwise the raw message.
    8. 
              
  8. Tìm thấy → fmt.Sprintf(message, args...) nếu len(args) > 0 và
                thông điệp chứa %; ngược lại trả thông điệp thô.
    9. 
            

            
Never returns an error or an empty string for a known key.

            
Không bao giờ trả lỗi, cũng không trả chuỗi rỗng với key đã biết.

Good to knowCần lưu ý

          

        

        

          
1There is no Vietnamese
              catalogLangVI exists, but no vi text ships with
              Junkit or Jungo. API_LANGUAGE=vi therefore still answers in English (fallback) until you add
              vi messages.LangVI có tồn tại, nhưng Junkit lẫn
              Jungo đều không kèm văn bản vi. Vì vậy API_LANGUAGE=vi vẫn trả tiếng Anh (dự
              phòng) cho tới khi bạn thêm thông điệp vi.

          
2Fallback is one level
              onlyrequested → default → key. After SetDefaultLang("vi")
              with an incomplete vi catalog, GetMessage("required", "fr", "email") returns
              "required" — English is not tried any more.được yêu cầu →
              mặc định → key. Sau SetDefaultLang("vi") mà catalog vi chưa đủ,
              GetMessage("required", "fr", "email") trả "required" — tiếng Anh không còn được
              thử nữa.

          
3Pass every
              argumentNo args → the raw template:
              GetMessage("required", "en") is "%[1]s is required". Too few → fmt noise:
              GetMessage("min", "en", "name") is
              "name must be longer than %!s(BADINDEX) characters".Không có
              args → trả template thô: GetMessage("required", "en") là "%[1]s is required".
              Thiếu args → lỗi của fmt: GetMessage("min", "en", "name") là
              "name must be longer than %!s(BADINDEX) characters".

          
4Typos are
              silentAn unknown key is returned as the message, so a misspelt key shows
              up as "user_not_fuond" in the API instead of failing. Grep responses for _ in
              tests.Key không tồn tại được trả về làm thông điệp, nên key gõ sai sẽ
              hiện thành "user_not_fuond" trên API thay vì báo lỗi. Hãy kiểm tra dấu _ trong
              response khi viết test.

          
5A literal % needs
              %%When args are passed and the text contains %, it goes
              through fmt.Sprintf: write "100%% done", not
              "100% done".Khi có args và văn bản chứa %, nó
              đi qua fmt.Sprintf: hãy viết "100%% done", không phải
              "100% done".

          
6One global
              namespaceAll features share one translator; the last
              AddTranslations for a key wins, and Fx invoke order decides which. Prefix keys with the
              feature name to avoid clashes.Mọi feature dùng chung một translator; lần
              AddTranslations cuối cùng cho một key sẽ thắng, và thứ tự invoke của Fx quyết định lần nào là
              cuối. Hãy đặt tiền tố tên feature cho key để tránh trùng.
