Junkit · response

response

The only way handlers write HTTP responses: one JSON envelope for every endpoint, translated messages, and domain errors (*AppError) mapped to HTTP status codes.

Cách duy nhất để handler ghi HTTP response: một JSON envelope cho mọi endpoint, message đã dịch, và lỗi domain (*AppError) được ánh xạ sang HTTP status code.

What it doesNó làm gì

A handler hands over a status code, a message key and (maybe) data or an error. The Responder turns that into the same JSON shape every time.

Handler chỉ cần truyền vào status code, i18n message key, cùng dữ liệu (data) hoặc lỗi (error). Responder sẽ chuẩn hóa thành định dạng JSON đồng nhất cho mọi API.

Or Send, Pagination, Error. Never ctx.JSON directly.
Hoặc Send, Pagination, Error. Không gọi ctx.JSON trực tiếp.
2 · translate2 · dịchi18n.Translator
"user_created" → "User created successfully" in the translator's default language.
"user_created" → "User created successfully" theo ngôn ngữ mặc định của translator.
3 · envelope3 · enveloperesponse.Response
status, code, message, data / error, plus api_info read from the gin context.
status, code, message, data / error, cộng api_info đọc từ gin context.
4 · JSON4 · JSONctx.JSON(status, …)
Written as-is with the status code; the Responder never aborts the chain.

SetupCài đặt

The Responder needs an *i18n.Translator — provide i18n.Module next to it.

Responder cần một *i18n.Translator — cung cấp i18n.Module ngay cạnh nó.

internal/app/fx.go
// in CoreModules(cfg)
i18n.Module,
fx.Invoke(func(t *i18n.Translator) { t.SetDefaultLang(cfg.Language) }),
response.Module,

The Responder has no options: every message uses the translator's default language, which Jungo sets from API_LANGUAGE (default en). Any constructor can now ask for response.Responder.

Responder không có options: mọi message dùng ngôn ngữ mặc định của translator, mà Jungo đặt từ API_LANGUAGE (mặc định en). Mọi constructor giờ có thể xin response.Responder.

main.go
translator := i18n.NewTranslator() // built-in English catalog
translator.AddTranslations(map[string]map[string]string{
    i18n.LangEN: {"user_created": "User created successfully"},
})

translator.SetDefaultLang(i18n.LangEN) // the language of every message ("en" is already the default)

responder := response.NewResponder(translator)

Without Fx, initialize the translator and pass it into response.NewResponder manually.

Không dùng Fx, tự khởi tạo translator và truyền thủ công vào response.NewResponder.

func (h *UserHandler) CreateUser(ctx *gin.Context) {
    var req v1dto.CreateUserRequest
    if !validation.BindJSON(ctx, h.responder, h.validator, &req) {
        return // the 422 is already written
    }

    user, err := h.service.CreateUser(ctx.Request.Context(), v1dto.ToCreateUserInput(req))
    if err != nil {
        h.responder.Error(ctx, err)
        return
    }

    h.responder.SendWithData(ctx, http.StatusCreated, "user_created", v1dto.NewUserResponse(user))
}

interfaceResponder
            

            

              
type Responder interface {
    Send(c *gin.Context, statusCode int, key string, args ...any)
    SendWithData(c *gin.Context, statusCode int, key string, data any, args ...any)
    Pagination(c *gin.Context, statusCode int, key string, data any, page pagination.Pagination, args ...any)
    Translate(key string, args ...any) string
    Error(c *gin.Context, err error)
}


            

            
In every method, key is a message key resolved in the translator's default language;
              args fill %[1]s-style verbs (only applied if the message contains
              %). Unknown keys are returned unchanged. None of the methods abort the gin chain —
              return after calling them.

            
Ở mọi method, key là message key được dịch theo ngôn ngữ mặc định của translator;
              args điền vào các verb kiểu %[1]s (chỉ áp dụng khi message có %).
              Key không tồn tại được trả về nguyên văn. Không method nào abort chuỗi gin — hãy return sau
              khi gọi.

1Plain 4xx AppErrors are not loggedAppError 4xx không có Cause thì không được logError calls c.Error(err) for
              non-AppError errors, 5xx AppErrors and any AppError with a
              Cause. A sentinel like response.New(response.NotFound, "…") is an expected
              outcome and stays out of the gin error list.Error gọi c.Error(err) với lỗi không phải
              AppError, AppError 5xx và mọi AppError có Cause. Lỗi
              sentinel như response.New(response.NotFound, "…") là kết quả bình thường nên không vào danh
              sách lỗi của gin.

          
2Register every keyĐăng ký mọi keyA key missing from the catalog is sent as the message verbatim
              ("failed_to_save_user"). Add texts with translator.AddTranslations (see i18n).Key không có trong catalog được gửi nguyên
              văn làm message ("failed_to_save_user"). Thêm văn bản bằng
              translator.AddTranslations (xem i18n).

          
3One language per processMột ngôn ngữ cho mỗi processThe translator's default language is the language of every
              response; there is no Accept-Language handling. Only English texts are built in, and the default language never
              falls back: with "vi", every key you haven't translated is sent as the raw key (e.g.
              api_not_found). Translate every key first, or keep en.Ngôn ngữ mặc định của translator là ngôn ngữ của mọi response; không xử lý Accept-Language.
              Chỉ có sẵn tiếng Anh, và ngôn ngữ mặc định không bao giờ dự phòng: với
              "vi", key nào bạn chưa dịch được gửi nguyên key (vd. api_not_found). Hãy dịch mọi key
              trước, hoặc giữ en.

          
4Call return yourselfTự gọi returnThe Responder writes the body but doesn't Abort().
              In middleware, call c.Abort() after it; in handlers, return.Responder ghi body nhưng không Abort(). Trong middleware, gọi
              c.Abort() sau đó; trong handler, return.

          
5AppError messages take no argsMessage của AppError không nhận argsError translates AppError.Message without arguments, so a text with
              %[1]s is sent with the verb left in. Give domain errors fixed texts, or use
              Send(c, status, key, args...).Error dịch
              AppError.Message không kèm tham số, nên văn bản có %[1]s được gửi đi với verb còn
              nguyên. Dùng văn bản cố định cho lỗi domain, hoặc dùng Send(c, status, key, args...).
