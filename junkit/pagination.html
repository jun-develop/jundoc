Use it in 30 secondsDùng ngay trong 30 giây

A complete list handler. Hover an explanation to light up its lines.

Một handler danh sách hoàn chỉnh. Rê chuột vào giải thích để làm sáng các dòng tương ứng.

product_dto.go
type ListProductsRequest struct {
    pagination.Request // page, page_size, search, sort_by, sort_order
}
product_handler.go
func (h *ProductHandler) List(ctx *gin.Context) {
    var req ListProductsRequest
    if err := ctx.ShouldBindQuery(&req); err != nil {
        h.responder.SendWithData(ctx, 422, "validation_error",
            h.validator.GetValidationErrors(ctx, err))
        return
    }
    req.SetDefaults("created_at", "desc")

    items, total, err := h.service.List(ctx, req.GetLimit(), req.GetOffset())
    if err != nil {
        h.responder.Error(ctx, err)
        return
    }

    meta := pagination.NewPagination(req.Page, req.PageSize, total)
    h.responder.Pagination(ctx, 200, "products_listed", items, meta)
}
1embed pagination.RequestYour request struct gets the five query params and their validation rules for free. Add your own filters next to it.Struct request của bạn có sẵn năm query param cùng luật kiểm tra. Thêm bộ lọc riêng ngay bên cạnh.
2ShouldBindQueryRejects page<1, page_size outside 1–100 and a sort_order other than asc / desc → answer 422.Từ chối page<1, page_size ngoài khoảng 1–100 và sort_order khác asc / desc → trả 422.
3SetDefaultsMissing page → 1, missing page_size → 10, empty sort → the values you pass.Thiếu page → 1, thiếu page_size → 10, sort trống → giá trị bạn truyền vào.
4GetLimit / GetOffsetBoth return int32 — the type sqlc generates for LIMIT / OFFSET params. Also count the total rows.Cả hai trả int32 — đúng kiểu sqlc sinh ra cho tham số LIMIT / OFFSET. Nhớ đếm luôn tổng số dòng.
5NewPagination + responder.PaginationBuilds the metadata and sends data: { items, pagination } (see response).Tạo metadata và gửi data: { items, pagination } (xem response).

method(*Request) GetOffset · GetLimit

        
func (r *Request) GetOffset() int32 // (Page - 1) * PageSize, clamped to math.MaxInt32
func (r *Request) GetLimit() int32  // PageSize


        
Call after SetDefaults, otherwise page 0 gives a negative offset.

        
Gọi sau SetDefaults, nếu không page 0 sẽ cho offset âm.

        
page has no upper bound, so a huge one (?page=3000000000) would overflow int32 into a negative OFFSET and a 500. GetOffset clamps it to math.MaxInt32 instead: the client just gets an empty page.

        
page không có giới hạn trên, nên một giá trị rất lớn (?page=3000000000) sẽ tràn int32 thành OFFSET âm và gây lỗi 500. GetOffset chặn nó ở math.MaxInt32: client chỉ nhận về một trang rỗng.

typePaginatedResponse[T]

        
type PaginatedResponse[T any] struct {
    Items      []T        `json:"items"`
    Pagination Pagination `json:"pagination"`
}


        
A typed version of the { items, pagination } shape — handy for API docs or clients. responder.Pagination builds the same JSON itself, so you don't need it there.
