The engine behind make feature NAME=product: derive name forms, render your text/template files (never overwriting), pick the next migration number, and add / remove the module in fx.go.

Wire it upKết nối vào app

Not part of your running app and not used with Fx: put a small package main under cmd/, call it from a Makefile target, run it from the project root (paths are relative to the working directory).

Không nằm trong app đang chạy và không dùng với Fx: đặt một package main nhỏ trong cmd/, gọi từ một target của Makefile, chạy ở thư mục gốc của project (đường dẫn tính theo thư mục làm việc).

Use it in 30 seconds: your own generatorDùng ngay trong 30 giây: generator của riêng bạn

A complete cmd/gen/main.go for a module named github.com/acme/api. Hover an explanation to light up its lines.

Một cmd/gen/main.go hoàn chỉnh cho module tên github.com/acme/api. Rê chuột vào giải thích để làm sáng các dòng tương ứng.

cmd/gen/main.go
package main

import (
    "flag"
    "path/filepath"

    "github.com/jun-develop/junkit/console"
    "github.com/jun-develop/junkit/scaffold"
)

const moduleTmpl = `package {{.Name}}

import "go.uber.org/fx"

// Module wires the {{.Pascal}} feature.
var Module = fx.Module("{{.Name}}")
`

const upTmpl = "CREATE TABLE {{.Table}} (id BIGSERIAL PRIMARY KEY);\n"

func main() {
    name := flag.String("name", "", "feature name in snake_case")
    flag.Parse()

    data := scaffold.NewFeatureData(*name, "github.com/acme/api", "")

    seq, err := scaffold.NextMigrationSeq("migrations")
    if err != nil {
        console.Fatalf("%v", err)
    }

    err = scaffold.Generate(scaffold.GenerateConfig{
        Data: data,
        Files: []scaffold.File{
            {Path: filepath.Join("internal/features", data.Name, "module.go"), Template: moduleTmpl},
            {Path: filepath.Join("migrations", seq+"_"+data.Table+".up.sql"), Template: upTmpl},
        },
        FxFile:     "internal/app/fx.go",
        ImportPath: "github.com/acme/api/internal/features/" + data.Name,
        Marker:     "// FEATURES",
        ModuleLine: data.Name + ".Module,",
    })
    if err != nil {
        console.Fatalf("%v", err)
    }
}

funcNewFeatureData · FeatureData

        
func NewFeatureData(name, module, table string) FeatureData

type FeatureData struct {
    Name   string // as given, snake_case: "order_item"
    Pascal string // "OrderItem"
    Camel  string // "orderItem"
    Plural string // Name pluralized: "order_items" (URL path segment)
    Table  string // table arg, or Plural: "order_items"
    Model  string // sqlc struct for Table, singularized: "OrderItem"
    Module string // your Go module path
}


        
    
          
  • Pascal: split on _, upper-case each part's first byte, drop empty parts. Camel: Pascal with the first byte lower-cased.
    • 
          
  • Pascal: tách theo _, viết hoa byte đầu của mỗi phần, bỏ phần rỗng. Camel: Pascal với byte đầu viết thường.
    • 
          
  • Plural: regular English rules only — consonant + y → ies (category → categories), s x z ch sh → +es (box → boxes), else +s. Irregular nouns (person → persons) are not handled — pass table for those.
    • 
          
  • Plural: chỉ theo quy tắc tiếng Anh thông thường — phụ âm + y → ies (category → categories), s x z ch sh → +es (box → boxes), còn lại +s. Danh từ bất quy tắc (person → persons) không được xử lý — hãy truyền table cho chúng.
    • 
          
  • Model: Table singularized the way sqlc names its structs, then Pascal (items → Item, categories → Category). Irregular plurals (people, children) are not covered. No validation of the name.
    • 
          
  • Model: Table chuyển về số ít theo cách sqlc đặt tên struct, rồi sang Pascal (items → Item, categories → Category). Số nhiều bất quy tắc (people, children) không được hỗ trợ. Không kiểm tra tên.
    • 
        

      


      

        
funcNextMigrationSeq

        
func NextMigrationSeq(dir string) (string, error)

        
    
          
  • Scans dir for names matching ^(\d{6})_.*\.up\.sql$, returns fmt.Sprintf("%06d", max+1). .down.sql and other files are ignored.
    • 
          
  • Quét dir tìm tên khớp ^(\d{6})_.*\.up\.sql$, trả về fmt.Sprintf("%06d", max+1). File .down.sql và file khác bị bỏ qua.
    • 
          
  • Missing or empty dir → "000001", nil. Other read errors → "" + read <dir>: ….
    • 
          
  • Thư mục không tồn tại hoặc rỗng → "000001", nil. Lỗi đọc khác → "" + read <dir>: ….

Steps, in order (fields of GenerateConfig are in Wire it up):

        
Các bước, theo thứ tự (các field của GenerateConfig ở mục Kết nối):

        
    
          
  1. If any File.Path exists → <path> already exists — refusing to overwrite, nothing written.
    2. 
          
  2. Nếu có File.Path nào đã tồn tại → <path> already exists — refusing to overwrite, không ghi gì.
    3. 
          
  3. Render every template with Data in memory first. Errors: parse template for …, render … — nothing written.
    4. 
          
  4. Render mọi template với Data trong bộ nhớ trước. Lỗi: parse template for …, render … — không ghi gì.
    5. 
          
  5. Then for each file: MkdirAll the parent (0755), write it; prints Created <path>. Errors: create directory for …, create … — the files already written are removed (the file that failed may remain, partially written).
    6. 
          
  6. Sau đó với mỗi file: MkdirAll thư mục cha (0755), ghi file; in Created <path>. Lỗi: create directory for …, create … — các file đã ghi trước đó bị xoá (file bị lỗi có thể vẫn còn, ghi dở).
    7. 
          
  7. gofmt -w on the .go outputs (failure → warning only).
    8. 
          
  8. gofmt -w các file .go đầu ra (lỗi → chỉ cảnh báo).
    9. 
          
  9. Add the import to FxFile → error add import: … (e.g. no existing "<module>" import found in … to anchor the new import next to).
    10. 
          
  10. Thêm import vào FxFile → lỗi add import: … (vd. no existing "<module>" import found in … to anchor the new import next to).
    11. 
          
  11. Insert ModuleLine after Marker → error add module line: … (e.g. marker "// FEATURES" not found in …).
    12. 
          
  12. Chèn ModuleLine sau Marker → lỗi add module line: … (vd. marker "// FEATURES" not found in …).
    13. 
          
  13. gofmt -w FxFile, prints Registered in ….
    14. 
          
  14. gofmt -w FxFile, in Registered in ….
    15. 
        

      


      

        
funcRemove · RemoveConfig

        
func Remove(cfg RemoveConfig) error

        
    
          
  1. Delete lines containing ModuleLine, then lines containing "ImportPath" from FxFile; gofmt -w. Errors: remove module line: …, remove import: … (e.g. FxFile unreadable — then nothing is deleted).
    2. 
          
  2. Xoá các dòng chứa ModuleLine, rồi các dòng chứa "ImportPath" trong FxFile; gofmt -w. Lỗi: remove module line: …, remove import: … (vd. không đọc được FxFile — khi đó chưa có gì bị xoá).

    6.

Good to knowCần lưu ý

    

    

      
1Files first, fx.go secondWriting the files is all-or-nothing: a template error writes nothing, a write error removes the files already written (the file that failed and directories it created may stay). But if the later fx.go step fails (no marker, no anchor import, wrong FxFile) all files are already on disk and stay there. Fix fx.go by hand or delete them before retrying — a rerun will refuse to overwrite.Việc ghi file là tất cả hoặc không gì cả: lỗi template thì không ghi gì, lỗi ghi thì xoá các file đã ghi (file bị lỗi và thư mục đã tạo có thể vẫn còn). Nhưng nếu bước fx.go sau đó lỗi (không có marker, không có import làm mốc, sai FxFile) thì mọi file đã nằm trên đĩa và vẫn ở đó. Sửa fx.go bằng tay hoặc xoá chúng trước khi chạy lại — chạy lại sẽ bị từ chối vì không ghi đè.

      
2Module must be setThe import goes after the last line anywhere in the file containing Module + "/". With an empty Module that is any line with a / — such as the // FEATURES comment.Import được chèn sau dòng cuối cùng trong cả file chứa Module + "/". Nếu Module rỗng thì đó là bất kỳ dòng nào có / — kể cả comment // FEATURES.

      
3Markers are substringsThe first line containing the marker wins. Pick a unique marker: // USER would also match a line // USERS above it.Dòng đầu tiên chứa marker sẽ được chọn. Hãy chọn marker duy nhất: // USER cũng sẽ khớp với dòng // USERS nằm phía trên.

      
4Remove matches substrings tooRemoving product deletes every line containing product.Module, — which also matches order_product.Module,. Check git diff after removing.Gỡ product sẽ xoá mọi dòng chứa product.Module, — khớp luôn cả order_product.Module,. Kiểm tra git diff sau khi gỡ.

      
5text/template, not htmlNothing is escaped. To emit a Go struct tag backtick inside a Go raw-string template, Jungo writes {{"`"}} via string concatenation.Không có gì được escape. Để in dấu backtick của struct tag bên trong template là raw string của Go, Jungo viết {{"`"}} bằng cách nối chuỗi.

      
6gofmt is optionalMissing gofmt only prints a warning; the inserted lines then keep their hard-coded tab indentation.Thiếu gofmt chỉ in cảnh báo; khi đó các dòng được chèn giữ nguyên thụt lề bằng tab cố định.
