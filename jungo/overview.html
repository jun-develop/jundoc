Jungo

A Go REST API skeleton built on Clean Architecture. Clone it, run 3 commands, and you have a production-ready API with authentication, user management, migrations, code scaffold, and CLI console — designed to scale cleanly feature by feature.

Bộ khung REST API viết bằng Go theo Clean Architecture. Clone về, chạy 3 lệnh là có ngay hệ thống hoàn chỉnh với Authentication (Opaque token), quản lý user, database migration, công cụ sinh code (Scaffold) và console CLI — cấu trúc chuẩn mực để mở rộng từng feature.

Add a featureThêm một feature mới

One command generates a complete CRUD feature matching internal/features/user — with Clean Architecture layers, migration, SQL queries, and automatic Fx wiring.

Một lệnh tạo ngay bộ API CRUD hoàn chỉnh, đúng chuẩn cấu trúc Clean Architecture như internal/features/user — tự động đăng ký dependency injection với Uber Fx.

1 · Generate1 · Sinh mã nguồn make feature NAME=product
Generates features/product/ (all 4 layers), DB migration, SQL queries, and registers the module in app/fx.go. Writing the files is all or nothing: if any file fails to render or write, the ones already written are removed. Registration in fx.go comes last — if it fails, the files stay (see scaffold).
Sinh toàn bộ thư mục features/product/ (đủ 4 tầng), file migration, file SQL, và tự động đăng ký module vào app/fx.go. Việc ghi file là tất cả hoặc không gì cả: chỉ cần một file render hay ghi lỗi là các file đã ghi bị xoá. Bước đăng ký vào fx.go chạy sau cùng — nếu lỗi, các file vẫn nằm lại (xem scaffold).
2 · Create table + Go code2 · Tạo bảng DB + code Go make migrate-up && make sqlc
Creates the table and its products:* permissions, then generates sqlc/product.sql.go — the project doesn't compile until you do. The app hot-reloads automatically.
Tạo bảng và các permission products:*, rồi sinh sqlc/product.sql.go — chưa chạy thì project không biên dịch được. Ứng dụng tự động hot-reload.

POST · GET · GET /:uuid · PATCH · DELETE
Fully functional CRUD endpoints ready immediately. Login + a products:* permission required, like users — the four permissions come with the feature (consts, labels, and the SQL in its migration), so make migrate-up is enough (details).
Có sẵn trọn bộ CRUD hoàn chỉnh. Bắt đăng nhập + permission products:*, giống users — bốn permission đi kèm feature (const, nhãn, và câu SQL trong migration của nó), nên chỉ cần make migrate-up (chi tiết).

Generated routes require login.Route sinh ra bắt đăng nhập. The generated router applies middleware.BearerAuth to the whole group, the same as features/user/router/v1/user_router.go (no valid access token → 401), and wraps each handler in guard.Can(…, domain.Products…) (missing permission → 403). Those four permissions are declared in the feature's own domain/permission.go (labels in its module.go) and inserted by its migration, granted to super_admin — so make migrate-up is all it takes, and removing the feature removes them too. To leave one endpoint public, register it outside that group with guard.Public, as auth_router.go does for /auth/login. Router sinh ra gắn middleware.BearerAuth cho cả group, giống features/user/router/v1/user_router.go (không có access token hợp lệ → 401), và bọc từng handler bằng guard.Can(…, domain.Products…) (thiếu permission → 403). Bốn permission đó được khai báo trong domain/permission.go của chính feature (nhãn nằm trong module.go của nó) và được migration của feature chèn vào, cấp cho super_admin — nên chỉ cần make migrate-up, và gỡ feature thì chúng cũng đi theo. Muốn để một endpoint public, đăng ký nó ngoài group đó với guard.Public, như auth_router.go làm với /auth/login.
4

CLI commands (console)Lệnh CLI (console)

A second entrypoint, cmd/console, for one-off jobs — creating the first admin, cleanups, backfills, reports. Shares the exact same config, DB and services as the API, but without starting the HTTP server.

Entrypoint thứ hai, cmd/console, chuyên dùng cho các tác vụ chạy 1 lần — tạo admin đầu tiên, dọn dẹp token, bù dữ liệu, chạy báo cáo. Dùng chung 100% cấu hình, DB và service với API, nhưng không chạy HTTP server.
