Four rules that keep the layers cleanBốn luật giữ các tầng sạch sẽ

1

Handler never touches SQL, and never decides business rules. It only translates HTTP ↔ service calls.

Handler không bao giờ đụng tới SQL, cũng không quyết định quy tắc nghiệp vụ. Nó chỉ làm nhiệm vụ tiếp nhận HTTP request, gọi Service và trả về JSON.

2

Service never imports Gin. It takes a context.Context and domain types, so the CLI and tests can call it too.

Service không bao giờ import thư viện Gin. Nó chỉ nhận context.Context và các kiểu dữ liệu Domain, nhờ đó logic nghiệp vụ có thể tái sử dụng dễ dàng trong cả lệnh CLI lẫn Unit Test.

3

Repository has no if-business-logic. It runs a query and turns database errors into domain errors (database.Match).

Repository không chứa logic nghiệp vụ rẽ nhánh. Nó chỉ tập trung thực thi query SQL và chuyển đổi lỗi database thành lỗi domain dễ hiểu (database.Match).

4

Layers talk through domain interfaces, never through concrete structs. That is what lets the test in step 3.9 swap the database for a fake.

Các tầng giao tiếp với nhau qua Interface trong domain, không bao giờ phụ thuộc trực tiếp vào struct cụ thể. Nhờ vậy bạn có thể dễ dàng mock (làm giả) database trong Unit Test.

3.1

Query — the SQLQuery — Câu lệnh SQL & sqlc

internal/database/primary/queries/product.sql

The query file is where you define how data is fetched or updated. We write standard SQL with special annotations that tell sqlc how to generate type-safe Go methods:

File query là nơi bạn định nghĩa các câu lệnh đọc/ghi dữ liệu. Ta viết SQL thuần kèm theo các chú thích (annotation) để sqlc hiểu và tự động sinh ra mã nguồn Go chuẩn mực:

queries/product.sql
-- name: UpdateProduct :one
UPDATE products SET
    name   = COALESCE(sqlc.narg(name), name),
    status = COALESCE(sqlc.narg(status), status)
WHERE uuid = sqlc.arg(uuid) AND deleted_at IS NULL
RETURNING *;
make sqlc → sqlc/product.sql.go (generated, don't edit)
type UpdateProductParams struct {
    Name   *string   `db:"name" json:"name"`     // narg → pointer: nil = NULL
    Status *int16    `db:"status" json:"status"`
    UUID   uuid.UUID `db:"uuid" json:"uuid"`
}

SyntaxCú pháp Meaning & Generated Go codeÝ nghĩa & Mã Go sinh ra
-- name: UpdateProduct :one Go method name & return type: :one returns a single row struct. (:many = slice of rows, :exec = executes without returning rows, :execrows = returns affected rows count). Khai báo tên method Go & kiểu kết quả: :one trả về 1 dòng (struct đơn). (:many = trả về slice danh sách, :exec = chỉ thực thi không trả về dòng, :execrows = trả về số dòng bị ảnh hưởng).
sqlc.narg(name) Nullable Argument: Tells sqlc this parameter can be NULL. In the generated Go struct, it becomes a pointer (*string), where nil represents an omitted field. Tham số có thể NULL: Báo cho sqlc biết tham số này có thể mang giá trị NULL. Trong struct Go sinh ra, trường này trở thành kiểu con trỏ (*string), giá trị nil đại diện cho việc client không gửi trường đó lên.
COALESCE(sqlc.narg(name), name) Dynamic Update technique: "If a new value is passed, update it; if omitted (NULL), keep the current column value". This ensures PATCH only modifies the fields sent in the request without overwriting untouched columns. Cập nhật linh hoạt: "Nếu có truyền giá trị mới thì cập nhật; nếu không gửi (NULL) thì giữ nguyên giá trị hiện tại trong DB". Nhờ vậy API PATCH chỉ cập nhật đúng các trường bạn gửi lên mà không bao giờ ghi đè làm mất dữ liệu cũ.
deleted_at IS NULL Soft Delete guard: Ensures deleted products cannot be updated or accidentally exposed to clients. Bảo vệ xóa mềm (Soft Delete): Đảm bảo không bao giờ cập nhật nhầm hoặc để lộ các sản phẩm đã bị xóa.

Changed a .sql file? Run make sqlc. Need a new column? That starts with a new migration (make migrate-create NAME=…, then make migrate-up) — never edit one that already ran.

Vừa sửa file .sql? Hãy chạy make sqlc để cập nhật code Go. Cần thêm cột mới vào bảng? Hãy tạo migration mới (make migrate-create NAME=… rồi make migrate-up) — tuyệt đối không sửa trực tiếp file migration đã từng được thực thi.

Plain Go, no Gin, no SQL. The input uses pointers so "not sent" (nil) is different from a value. Each layer gets one method in an interface. 3.3

Repository — run the queryRepository — thực thi câu truy vấn

internal/features/product/repository/product_repository.go

Turns the domain input into sqlc params, runs the query, turns the row back into a domain Product. The repository holds a *primary.DB; r.db.Queries(ctx) returns the sqlc queries and automatically joins a transaction if the caller started one. database.Match turns "no row matched" (wrong or deleted uuid) into your 404 error; any other error passes through and becomes a 500.

Repository có nhiệm vụ chuyển đổi input từ Domain thành params cho sqlc, thực thi câu query, rồi map dòng kết quả về entity Product của Domain. Repository giữ một *primary.DB; hàm r.db.Queries(ctx) trả về các query của sqlc và sẽ tự động tham gia vào Database Transaction nếu Service phía trên đang mở transaction. Tiện ích database.Match tự động bắt lỗi "không tìm thấy bản ghi" (do sai UUID hoặc sản phẩm đã bị xóa) và chuyển thành lỗi domain.ErrProductNotFound (HTTP 404); mọi lỗi không xác định khác sẽ được chuyển tiếp để trả về mã 500.

repository/product_repository.go
// Update implements domain.ProductRepository.
func (r *ProductRepository) Update(ctx context.Context, uid uuid.UUID, input domain.UpdateProductInput) (*domain.Product, error) {
    row, err := r.db.Queries(ctx).UpdateProduct(ctx, sqlc.UpdateProductParams{
        UUID:   uid,
        Name:   input.Name,
        Status: input.Status,
    })
    if err != nil {
        return nil, database.Match(err, map[database.ErrorType]error{
            database.ErrorNotFound: domain.ErrProductNotFound,
        })
    }

    return mapProduct(row), nil
}

3.4

Service — the business logicService — xử lý logic nghiệp vụ

internal/features/product/service/product_service.go

The place for rules. Editing a name has no rule yet, so the service only saves and clears the cache. GetProduct caches products for 5 minutes, so after a write the cache key must go, or readers keep seeing the old name. Write the flow in the doc comment — the whole codebase does.

Service là trái tim của hệ thống — nơi lưu giữ toàn bộ quy tắc nghiệp vụ (Business Rules). Ở ví dụ cập nhật tên này, logic rất tinh gọn: gọi repository để lưu vào DB và xóa cache cũ. Vì hàm GetProduct cache sản phẩm trong Redis 5 phút, nên sau khi ghi thành công bắt buộc phải xóa cache key, nếu không client sẽ tiếp tục nhìn thấy tên cũ. Hãy luôn ghi tóm tắt luồng xử lý (Flow) ngay trong comment của hàm — toàn bộ codebase đều tuân thủ quy chuẩn này.

service/product_service.go
// UpdateProduct updates product information.
//
// Flow: update in DB -> invalidate cache
func (s *ProductService) UpdateProduct(ctx context.Context, uid uuid.UUID, input domain.UpdateProductInput) (*domain.Product, error) {
    updated, err := s.repo.Update(ctx, uid, input)
    if err != nil {
        return nil, err
    }

    _ = s.cache.Delete(ctx, cacheKey(uid))

    return updated, nil
}

// UpdateProduct handles PATCH /products/:uuid.
func (h *ProductHandler) UpdateProduct(ctx *gin.Context) {
    uid, ok := httpx.ParseUUID(ctx, h.responder, h.validator)
    if !ok {
        return
    }

    var req v1dto.UpdateProductRequest
    if err := ctx.ShouldBindJSON(&req); err != nil {
        h.responder.SendWithData(ctx, http.StatusUnprocessableEntity, "validation_error", h.validator.GetValidationErrors(ctx, err))
        return
    }

    item, err := h.service.UpdateProduct(ctx.Request.Context(), uid, v1dto.ToUpdateProductInput(req))
    if err != nil {
        h.responder.Error(ctx, err)
        return
    }

    h.responder.SendWithData(ctx, http.StatusOK, "product_updated", v1dto.NewProductResponse(item))
}

func (r *ProductRoutes) Version() string {
    return "v1" // → everything below lives under /api/v1

// Register implements router.Routes; every route requires a logged-in user.
func (r *ProductRoutes) Register(group *gin.RouterGroup) {
    items := group.Group("/products")
    items.Use(middleware.BearerAuth(r.authenticator, r.responder, middleware.BearerAuthOptions{}))

    items.POST("", r.handler.CreateProduct)
    items.GET("", r.handler.ListProducts)
    items.GET("/:uuid", r.handler.GetProduct)
    items.PATCH("/:uuid", r.handler.UpdateProduct)
    items.DELETE("/:uuid", r.handler.DeleteProduct)
}

5.2 · ?t_debug — an X-ray of one request5.2 · ?t_debug — Chụp X-quang toàn diện một request

Add ?t_debug=<value> to any URL and send the header X-Internal-Secret: <AUTH_INTERNAL_SECRET> (in a browser, add it with an extension such as ModHeader). Giá trị bí mật này được định nghĩa bởi biến TRACER_DEBUG_VALUE trong file .env của bạn (mặc định là 0604, mỗi môi trường nên đặt một giá trị khác nhau; tên tham số là TRACER_DEBUG_KEY, mặc định là t_debug). ▸

Every SQL query with real values, its duration, its result row(s) or its error with file:line.

Toàn bộ các câu lệnh SQL kèm giá trị thực tế, thời gian thực thi, các dòng kết quả hoặc thông báo lỗi cụ thể kèm vị trí file:dòng.

▸

A timeline, DB time vs total time, and request/server info (headers with Authorization masked).

Biểu đồ thời gian (Timeline), tỷ lệ thời gian chạy DB so với tổng thời gian xử lý, cùng thông tin chi tiết về request và server (các header nhạy cảm như Authorization đều được tự động che đi).

▸

Your own notes from tracer.V, tracer.Span… (5.3).

Các giá trị theo dõi tùy biến do bạn chủ động in ra từ code thông qua tracer.V, tracer.Span… (xem mục 5.3).

▸

Browser → an HTML dashboard. curl / httpie / wget → the same as JSON.
