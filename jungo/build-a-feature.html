Four rules that keep the layers cleanBốn luật giữ các tầng tách biệt

1

Handler never touches SQL, and never decides business rules. It only translates HTTP ↔ service calls.

Handler không bao giờ đụng tới SQL, cũng không quyết định quy tắc nghiệp vụ. Nó chỉ làm nhiệm vụ tiếp nhận HTTP request, gọi Service và trả về JSON.

2

Service never imports Gin. It takes a context.Context and domain types, so the CLI and tests can call it too.

Service không bao giờ import thư viện Gin. Nó chỉ nhận context.Context và các kiểu dữ liệu Domain, nhờ đó logic nghiệp vụ có thể tái sử dụng dễ dàng trong cả lệnh CLI lẫn Unit Test.

3

Repository has no if-business-logic. It runs a query and turns database errors into domain errors (database.Match).

Repository không chứa logic nghiệp vụ rẽ nhánh. Nó chỉ tập trung thực thi query SQL và chuyển đổi lỗi database thành lỗi domain dễ hiểu (database.Match).

4

Layers talk through domain interfaces, never through concrete structs. That is what lets the test in step 3.9 swap the database for a fake.

Các tầng giao tiếp với nhau qua Interface trong domain, không bao giờ phụ thuộc trực tiếp vào struct cụ thể. Nhờ vậy bạn có thể dễ dàng mock (làm giả) database trong Unit Test.

Query — the SQLQuery — Câu lệnh SQL & sqlc

internal/database/primary/queries/product.sql

The query file is where you define how data is fetched or updated. We write standard SQL with special annotations that tell sqlc how to generate type-safe Go methods:

File query là nơi bạn định nghĩa cách đọc hoặc ghi dữ liệu. Ta viết SQL chuẩn kèm các annotation để sqlc sinh method Go an toàn kiểu:

queries/product.sql
-- name: UpdateProduct :one
UPDATE products SET
    name   = COALESCE(sqlc.narg(name), name),
    status = COALESCE(sqlc.narg(status), status)
WHERE uuid = sqlc.arg(uuid) AND deleted_at IS NULL
RETURNING *;

type UpdateProductParams struct {
    Name   *string   `db:"name" json:"name"`     // narg → pointer: nil = NULL
    Status *int16    `db:"status" json:"status"`
    UUID   uuid.UUID `db:"uuid" json:"uuid"`
}

Khai báo tên method Go & kiểu kết quả: :one trả về 1 dòng (struct đơn). (:many = trả về slice danh sách, :exec = chỉ thực thi không trả về dòng, :execrows = trả về số dòng bị ảnh hưởng).
sqlc.narg(name) Nullable Argument: Tells sqlc this parameter can be NULL. In the generated Go struct, it becomes a pointer (*string), where nil represents an omitted field. Tham số có thể NULL: Báo cho sqlc biết tham số này có thể mang giá trị NULL. Trong struct Go sinh ra, trường này trở thành kiểu con trỏ (*string), giá trị nil đại diện cho việc client không gửi trường đó lên.
COALESCE(sqlc.narg(name), name) Dynamic Update technique: "If a new value is passed, update it; if omitted (NULL), keep the current column value". This ensures PATCH only modifies the fields sent in the request without overwriting untouched columns. Cập nhật linh hoạt: "Nếu có truyền giá trị mới thì cập nhật; nếu không gửi (NULL) thì giữ nguyên giá trị hiện tại trong DB". Nhờ vậy API PATCH chỉ cập nhật đúng các trường bạn gửi lên mà không bao giờ ghi đè làm mất dữ liệu cũ.

3.3

Repository — run the queryRepository — thực thi câu truy vấn

internal/features/product/repository/product_repository.go

Turns the domain input into sqlc params, runs the query, turns the row back into a domain Product. The repository holds a *primary.DB; r.db.Queries(ctx) returns the sqlc queries and automatically joins a transaction if the caller started one. database.MatchNotFound turns "no row matched" (wrong or deleted uuid) into your 404 error; wrap adds the operation name to any other error, which becomes a 500. See database.

Đổi input của domain thành params của sqlc, chạy query, rồi đổi dòng kết quả về Product của domain. Repository giữ một *primary.DB; r.db.Queries(ctx) trả về các query của sqlc và tự tham gia transaction nếu nơi gọi đã mở một transaction. database.MatchNotFound đổi lỗi "không có dòng nào khớp" (sai UUID hoặc đã bị xóa) thành lỗi 404 của bạn; wrap gắn tên thao tác vào mọi lỗi khác, lỗi đó thành 500. Xem database.

repository/product_repository.go
// Update implements domain.ProductRepository.
func (r *ProductRepository) Update(ctx context.Context, uid uuid.UUID, input domain.UpdateProductInput) (*domain.Product, error) {
    row, err := r.db.Queries(ctx).UpdateProduct(ctx, sqlc.UpdateProductParams{
        UUID:   uid,
        Name:   input.Name,
        Status: input.Status,
    })
    if err != nil {
        return nil, wrap("update", database.MatchNotFound(err, domain.ErrProductNotFound))
    }

    return mapProduct(row), nil
}

// wrap adds the failed operation to err; domain errors stay matchable with errors.Is/As.

// UpdateProductRequest is the request body for PATCH /products/:uuid.
type UpdateProductRequest struct {
    Name   *string `json:"name" binding:"omitempty,min=2,max=150"`
    Status *string `json:"status" binding:"omitempty,oneof=active inactive"`
}

// ToUpdateProductInput converts UpdateProductRequest to domain input.
func ToUpdateProductInput(req UpdateProductRequest) domain.UpdateProductInput {
    var status *int16
    if req.Status != nil {
        // The binding tag guarantees a known name.
        if s, ok := domain.ParseProductStatus(*req.Status); ok {
            status = &s
        }
    }

    return domain.UpdateProductInput{Name: req.Name, Status: status}
}

// Register implements router.Routes; every route requires a logged-in user holding its permission.
func (r *ProductRoutes) Register(group *gin.RouterGroup) {
    productGroup := group.Group("/products", gin.HandlerFunc(r.authenticate))

    productGroup.POST("", r.guard.Can(r.handler.CreateProduct, domain.ProductsCreate))
    productGroup.GET("", r.guard.Can(r.handler.ListProducts, domain.ProductsRead))
    productGroup.GET("/:uuid", r.guard.Can(r.handler.GetProduct, domain.ProductsRead))
    productGroup.PATCH("/:uuid", r.guard.Can(r.handler.UpdateProduct, domain.ProductsUpdate))
    productGroup.DELETE("/:uuid", r.guard.Can(r.handler.DeleteProduct, domain.ProductsDelete))
}

Checklist before you open a PRChecklist trước khi tạo PR

✓

New migration pair with a working down; old migrations untouched.

Tạo đủ cặp migration mới với hàm down hoạt động chuẩn xác; tuyệt đối không sửa các migration cũ.

✓

make sqlc run and the generated files committed.

Đã chạy make sqlc và commit đầy đủ các file Go được sinh tự động.

✓

Rules live in the service; the handler only translates HTTP.

Mọi quy tắc nghiệp vụ nằm gọn trong Service; Handler chỉ làm nhiệm vụ tiếp nhận và điều phối HTTP.

✓

Routes stay inside the authenticated group, each wrapped by the Guard with its own permission (in the feature's domain/permission.go and in a migration); any guard.Public one is deliberate and reviewed.

Các endpoint đều nằm trong group có xác thực, mỗi cái bọc bằng Guard với permission riêng (có trong domain/permission.go của feature và trong một migration); endpoint guard.Public nào cũng phải có lý do rõ ràng và được review kỹ.

✓

Every new route has its line in Docs(), and its DTO fields carry binding and example tags, so /docs shows them.

Mỗi route mới có dòng tương ứng trong Docs(), và field của DTO có tag binding và example, để /docs hiển thị đủ.

✓

Every new message key has its text in registerTranslations.

Mọi key thông báo mới đều được khai báo bản dịch đầy đủ trong registerTranslations.

✓

If you cache an entity, every write that changes it deletes the cached entry.

Nếu có cache một entity, mọi thao tác ghi làm thay đổi nó đều xóa entry trong cache.

✓

A test for each service branch; make test and make vet pass; make fmt run.

Đã viết Unit Test cho từng nhánh logic của Service; các lệnh make test, make vet và make fmt đều pass.

✓

No tracer.Stop left, no secrets in logs.

Đã xóa hết các dòng tracer.Stop thử nghiệm, không để lọt mật khẩu hay thông tin bí mật trong log.
